# D. 单篇论文方法卡片

## 01. LightGaussian: Unbounded 3D Gaussian Compression with 15x Reduction and 200+ FPS

来源：[Project Page](https://lightgaussian.github.io/)

### 基本信息

```text
年份/会议：NeurIPS 2024 Spotlight
所属分类：C / S / Q
方法阶段：训练后压缩 + recovery fine-tune
对我重要性：★★★
```

### 解决的问题

原始 3DGS 在复杂场景中会从 SfM 稀疏点增长到百万级 Gaussian，导致单场景 checkpoint 很大、存储成本高、带宽和渲染效率受影响。直接按 opacity 剪枝太粗糙，容易误删对视角、边缘或背景有贡献的 Gaussian。

### 核心方法

1. Global Significance Score
   - 不只看 opacity，而是看 Gaussian 在所有训练视角、所有像素射线中的实际渲染贡献。
   - 重要因素包括 hit count、opacity、transmittance、volume。

2. Gaussian Pruning + Co-adaptation
   - 根据全局重要性分数排序，删掉低分 Gaussian。
   - 剩余 Gaussian 不再 densification，而是 fine-tune attributes 来恢复质量。

3. SH Distillation
   - teacher 使用完整高阶 SH。
   - student 使用低阶 compact SH。
   - 用真实训练视角和 pseudo-view 做像素级蒸馏，尽量保留 view-dependent 高光和反光。

4. Vector Quantization
   - 主要对低重要性 SH 系数做 VQ。
   - 位置、旋转、scale、opacity 等敏感属性通常保留更高精度。

### Pipeline

```text
Train vanilla 3DGS
↓
Compute global significance for each Gaussian
↓
Prune low-significance Gaussians
↓
Fine-tune remaining Gaussians for recovery
↓
Distill full SH teacher to compact SH student
↓
Apply VQ to selected low-significance SH attributes
↓
Store compact model
```

### 关键 score / 公式要记什么

```text
GS_j ≈ Σ over all training pixels:
hit(G_j, ray_i) × opacity_j × transmittance × volume_factor
```

理解重点：
- hit count：这个 Gaussian 被多少训练像素/射线看到。
- opacity：它本身透明度高不高。
- transmittance：前面有没有别的 Gaussian 挡住它。
- volume：它覆盖范围大不大，==但要归一化，避免背景大 Gaussian 被过度高估。==

### 实验要记

```text
关注指标：
Size / FPS / PSNR / SSIM / LPIPS / Gaussian 数量

核心结论：
能达到约 15x 压缩，同时 FPS 提升到 200+，质量损失较小。
```

### Ablation 结论

- 只剪枝会损失质量，recovery fine-tune 很重要。
- 直接降低 SH degree 会损失高光/反光，distillation 能明显恢复。
- VQ 要选择性做，对所有属性一刀切量化会损失精度。

### 局限

- 计算全局 significance 需要遍历训练视角和像素，成本不低。
- 主要是 general 3DGS 压缩，没有直接考虑 semantic / object / edge-aware。
- 对动态 Avatar / human Gaussian 迁移时，需要考虑 SMPL-X topology。

## 02. FastGS: Training 3D Gaussian Splatting in 100 Seconds

来源：[Project Page](https://fastgs.github.io/) ｜ [CVPR 2026 Paper](https://openaccess.thecvf.com/content/CVPR2026/html/Ren_FastGS_Training_3D_Gaussian_Splatting_in_100_Seconds_CVPR_2026_paper.html) ｜ [Code](https://github.com/fastgs/FastGS)

### 基本信息

```
年份/会议：CVPR 2026 Highlight
所属分类：C / S / T
方法阶段：训练阶段的 densification + pruning + rasterizer 加速
对我重要性：★★★★★
```

`C` 表示 Compression/Capacity Control，`S` 表示 Selection，`T` 表示 Training Acceleration。

### 解决的问题

原始 3DGS 的主要训练瓶颈不是单次渲染慢，而是训练过程中 Gaussian 会持续 densify：

```
训练早期不断 clone / split
↓
Gaussian 数快速膨胀
↓
每个 view 的投影、tile pair、排序、alpha blending 都更贵
↓
训练后期大量 Gaussian 已冗余，但仍参与前向和反向传播
```

许多加速方法只在训练后剪枝，或者靠固定 Gaussian budget 限制数量。但这会出现两类问题：

- 太早限制数量，细节不够、质量下降；
- 太晚剪枝，前面已经付出了大量无效训练成本。

FastGS 的核心目标是：根据 Gaussian 的多视角一致性，决定哪些点值得继续 densify，哪些点应该尽早删除，从训练过程本身控制容量。

### 核心方法

#### 1. Multi-view Consistent Densification, VCD

原始 3DGS 的 densification 往往依赖单视角的 2D position gradient。问题是：一个 Gaussian 在某一张训练图上梯度大，不代表它在其他视角真的缺少几何/外观表达。

FastGS 用多视角一致性筛选 densification 候选：

```
一个 Gaussian 在多个相机视角中
都表现为误差大 / 投影不稳定 / 覆盖不足
↓
认为它是“真实需要细化”的点
↓
允许 clone 或 split
```

直觉上：

- 单视角梯度高，可能是噪声、遮挡或特定视角的局部现象；
- 多视角一致地需要细化，更可能对应真实几何或高频外观；
- 因此可以减少无效 clone/split，抑制 Gaussian 数爆炸。

#### 2. Multi-view Consistent Pruning, VCP

VCP 在训练中定期识别低价值 Gaussian 并删除。论文的关键不是简单 `opacity < threshold`，而是利用多视角渲染行为评估其贡献。

可以把它理解为：

```
一个 Gaussian 如果在多数训练视角中：
- 很少可见
- 常被前景遮挡
- 对像素颜色影响很弱
- 与其他 Gaussian 高度冗余
↓
它更适合被删除
```

这让 pruning 与 densification 形成闭环：

```
VCD：把容量给真正欠拟合的区域
VCP：回收跨视角持续低价值的区域
```

#### 3. Compact Box

Compact Box 是 FastGS 的 rasterizer 侧加速模块。它通过更紧的有效支持范围，减少 Gaussian 对像素/tile 的无效影响区域。

概念上：

```
原始 Gaussian 投影范围较宽
↓
同一个 Gaussian 覆盖更多 tile / pixel
↓
产生更多 Gaussian-tile pairs 和 blending 计算

Compact Box：
只保留足够有贡献的紧凑区域
↓
降低无效覆盖与 rasterization 开销
```

它不是减少模型总点数，而是减少某次渲染中“这个 Gaussian 需要参与多少 tile/pixel”的范围。

### Pipeline

```
Initialize 3DGS from SfM points
↓
Train and collect multi-view statistics
↓
VCD:
only densify Gaussians with multi-view-consistent need
↓
VCP:
prune Gaussians with consistently low multi-view value
↓
Use Compact Box to reduce rasterization overhead
↓
Finish training with controlled Gaussian capacity
```

### 关键 score / 机制要记什么

```
单视角梯度大
≠
这个 Gaussian 一定需要 split
```

FastGS 的关键是多视角一致性。它把“是否需要新增容量”与“是否需要删除容量”都从单视角局部判断，提升为跨视角判断。

对 VCP，可以理解为如下概念分数：

```
PruneScore(G_j)
≈ low visibility
+ low rendered contribution
+ high occlusion / redundancy
+ low multi-view consistency
```

不是所有实现都公开成一个固定公式；更重要的是它以多视角渲染统计驱动训练期的容量调控。

### Tile / Bucket 与 FastGS 的关系

FastGS 使用 tile-based rasterizer。对于一张图：

```
Gaussian
↓ 投影
Gaussian-tile pair
↓ 深度排序
tile 内 pair list
↓ 每 32 个 pair 分成一个 bucket
↓
renderCUDA alpha blending
```

```
num_rendered
= Gaussian-tile pairs 总数

num_buckets
= tile 内 pair list 按固定 bucket 容量分块后的总 bucket 数

pairs_per_bucket
= num_rendered / num_buckets
```

这些不是最终可见 Gaussian 总数，而是 rasterizer 实际需要处理的工作量。

### 实验要记

```
论文关注：
Training Time / PSNR / SSIM / LPIPS / Gaussian Count / GPU Memory

论文主张：
静态场景可约 100 秒完成训练；
相对不同 baseline 有约 2-7x 的训练加速；
在一些基准上相对 vanilla 3DGS 可达到更大的训练加速。
```

论文实验覆盖静态重建、动态场景、稀疏视角、表面重建、大场景和 SLAM，强调框架可迁移性。[FastGS Project Page](https://fastgs.github.io/)

### Ablation 结论

- 只做 densification 控制，不能充分回收冗余容量；
- 只做 pruning，可能过早删除潜在有用点；
- VCD 与 VCP 联合，才形成“生成有效点 + 删除冗余点”的容量闭环；
- Compact Box 是 rasterizer 侧辅助加速，不替代训练期 Gaussian 容量控制。

### 局限

- 多视角统计本身有额外计算成本；
- 方法效果与当前训练视角分布有关，极稀疏视角时“多视角一致性”证据会减弱；
- Compact Box 的 pair 减少不一定稳定转化为端到端 FPS，取决于 GPU、kernel、pair 数量和其他框架开销；
- VCD/VCP 改变了训练历史，因此不能只用最终 pruning score 的局部比较解释全部收益。

## 03. Speeding Up the Learning of 3D Gaussians with Much Shorter Gaussian Lists

来源：[arXiv](https://arxiv.org/abs/2603.09277) ｜ [Code](https://github.com/MachinePerceptionLab/ShorterSplatting)

### 基本信息

```
常用简称：ShorterSplatting
年份/会议：2026，CVPR 2026 相关工作
所属分类：T / R / L
方法阶段：训练期的 Gaussian list 缩短
对我重要性：★★★★★
```

`T` 表示 Training Acceleration，`R` 表示 Rasterization Efficiency，`L` 表示 Loss/Regularization。

### 解决的问题

即使总 Gaussian 数不变，3DGS 的渲染成本也可能很高。

因为一个像素沿视线会有一个深度排序后的 Gaussian list：

```
pixel ray
↓
G1, G2, G3, ..., GN
↓
逐个计算 alpha、transmittance、blending
↓
前向渲染 + 反向梯度
```

如果每个像素/tile 的 list 很长：

- alpha blending 操作变多；
- 内存访问增多；
- 反向传播更重；
- training iteration 更慢。

论文的核心观点是：

```
总 Gaussian 数量
不等于
真实 rasterization 工作量
```

因此它不主要依赖删更多 Gaussian，而是让每个 Gaussian 更聚焦于它真正主导的像素区域，使每条 ray 上需要参与 alpha blending 的 Gaussian 更少。

### 核心方法

#### 1. Scale Reset

论文定期将所有 Gaussian 的 scale 按比例缩小：

```
s_i ← ζ × s_i
其中 ζ < 1
```

含义是：

```
Gaussian 更小
↓
覆盖更少附近像素 / tile
↓
更少进入这些像素的 Gaussian list
↓
list 变短
```

它不是永久把模型“压扁后不管”，而是：

```
Scale Reset
↓
继续训练若干 iteration
↓
position / opacity / SH / rotation / scale 继续共同优化
↓
逐渐恢复有效的辐射场表达
```

论文强调 reset 之间要有足够的优化窗口，让属性重新适配。它还观察到 reset 后通常会形成较小 scale 与较高 opacity 的表示。

#### 2. Entropy Constraint

对于某个像素，按深度排序的 Gaussian 权重为：

```
w_i(p) = T_i(p) × α_i(p)  它对最终像素真正贡献了多少
```

其中：

```
α_i(p) = opacity_i × projected_gaussian_i(p)  Gaussian 自己在该像素的 alpha

T_i(p) = Π over k<i (1 - α_k(p))  光线到达它之前还剩多少
```

```
σ：Gaussian 自己整体有多不透明
g(p)：它在这个像素位置还剩多强
α(p)：它此刻对该像素实际挡住/贡献多少
w=Tα：考虑前方遮挡后，它最终真正贡献多少
```
还要把背景残余透射率作为最后一个概率：

```
w_bg(p) = T_final(p)
```

于是：

```
Σ_i w_i(p) + w_bg(p) = 1
```

这很重要，因为它使权重天然构成概率分布，不需要额外归一化。

逐像素 entropy：

```
H(p) = - Σ_i w_i(p) log w_i(p)
       - T_final(p) log T_final(p)
```

总体 entropy loss：

```
L_entropy = mean over pixels of H(p)

L_total = L_photo + γ × L_entropy
```

最小化 entropy 后：

```
原本：
一个像素由很多 Gaussian 以小权重共同解释

Entropy 后：
少数主导 Gaussian 权重更大
大量次要 Gaussian 权重更小
↓
每个 Gaussian 更集中服务于自己的主要区域
↓
对邻近像素的弱影响减少
↓
Gaussian list 变短
```

这不是“直接删除 Gaussian”，也不是单独压低 opacity；它通过可微 alpha blending 改变 position、scale、opacity、rotation 等属性的联合优化方向。

#### 3. Resolution Scheduler（会影响VCD）

论文把 Scale Reset 和 Entropy 放进渐进分辨率训练：

```
低分辨率训练
↓
较少 pixel / 更便宜的 rasterization
↓
逐步提高训练分辨率
↓
在后期恢复高频细节
```

它的作用是进一步减少早期训练成本，与更短 Gaussian list 互补。

### Pipeline

```
Initialize 3DGS / LiteGS
↓
正常训练与 densification
↓
周期性 Scale Reset
↓
每一轮在 alpha blending 中计算 entropy loss
↓
继续优化，让属性在 reset 后重新适配
↓
按预设阶段提升训练分辨率
↓
得到相同或相近 Gaussian 数量，
但每个 pixel/tile 的 Gaussian list 更短的模型
```

### 关键公式要记什么

```
w_i = T_i α_i
T_i = Π_{k<i}(1 - α_k)
w_bg = T_final

H = -Σ_i w_i log(w_i) - w_bg log(w_bg)

L = L_photo + γL_entropy
```

理解重点：

- Entropy 约束的是沿一条 ray 的混合权重分布；
- 背景的 residual transmittance 也必须纳入 entropy；
- 不必显式归一化，因为 Gaussian 权重加背景权重天然和为 1；
- 它不是逐 Gaussian 的“重要性分数”，而是逐像素、逐 ray 的可微正则化。

### 实验要记

```
关注指标：
Training Time
PSNR / SSIM / LPIPS
Gaussian list length distribution
每 tile / 每 pixel 的 list length heatmap
Inference FPS

论文主张：
主要靠缩短 list，而非仅减少 Gaussian 总数；
在 Mip-NeRF 360 等基准中保持相近质量并显著缩短训练时间。
```

论文展示中，示例场景训练时间从原始 3DGS 的约 `919.51 s`、LiteGS 的约 `191.17 s` 降到方法的约 `99.58 s`；这是示例而非所有场景的统一常数。[ShorterSplatting paper](https://www.alphaxiv.org/abs/2603.09277)

### Ablation 结论

- `Scale Reset` 单独使用：直接缩小空间覆盖，立刻降低 list 长度；
- `Entropy` 单独使用：使权重更尖锐，弱化次要 Gaussian 对邻域像素的影响；
- `Scale Reset + Entropy`：几何上的覆盖收缩与权重分布收缩互补；
- 仅对 opacity 施加极化/二值化约束不如 entropy，因为 entropy 同时通过渲染权重作用于 opacity、scale、position、rotation；
- 单纯改变 tile size 不一定有效：tile 更小会让每 tile list 更短，但 tile 数变多，整体训练时间可能相近。

### 局限

- Scale Reset 的时机、缩放比例和下一次 reset 前的恢复窗口很敏感；
- 若 reset 与激进 pruning 在同一 iteration 发生，模型可能没有机会修复属性，质量会明显受损；
- Entropy 可能改善 LPIPS/SSIM 与 list 长度，却带来小幅 PSNR 代价；
- 额外的 entropy forward/backward 实现必须保持高效，否则正则化本身会抵消部分速度收益；
- 论文的 list 定义常更接近 per-pixel/per-tile workload；不同 rasterizer 的 `num_rendered`、bucket 和像素 list 不能混为同一个绝对量。

## 04. Prune Wisely, Reconstruct Sharply

来源：[CVPR 2026 Open Access](https://openaccess.thecvf.com/content/CVPR2026/html/Wang_Prune_Wisely_Reconstruct_Sharply_Compact_3D_Gaussian_Splatting_via_Adaptive_CVPR_2026_paper.html)

### 基本信息

```text
年份/会议：CVPR 2026
所属分类：P / E / G
方法阶段：训练中 adaptive pruning + compact model recovery
对我重要性：★★★
```

### 解决的问题

3DGS 为了高质量会产生大量 primitive。剪枝能减少冗余，但如果剪得太早、太多或只看简单指标，会导致细节损失。普通 Gaussian 在 compact 数量下表达边缘和纹理能力有限，所以 aggressive pruning 后边缘容易糊。

### 核心方法

1. Reconstruction-aware Pruning Scheduler
   - 根据重建质量决定剪枝时机。
   - 不是固定 interval 机械剪枝，而是看模型是否已经恢复到可以继续剪的状态。

2. Adaptive Pruning Ratio
   - 不同阶段剪枝比例不同。
   - 避免早期过度剪枝，也避免后期压缩不足。

3. Pruning Score
   - 不只考虑 opacity。
   - 融合空间和频率/细节相关信息，保护更重要的结构区域。

4. 3D Difference-of-Gaussians Primitive
   - 一个 3D-DoG = primary Gaussian - pseudo Gaussian。
   - 形成中心正密度峰和周围负密度环。
   - 更适合表达边缘、边界和高频细节。

5. 3D-DoG Density Control
   - 不是所有 DoG 永远保留。
   - pseudo Gaussian 贡献很低时退化回普通 Gaussian，减少额外开销。

### Pipeline

```text
Train 3DGS
↓
Monitor reconstruction state
↓
Adaptive pruning scheduler decides pruning time
↓
Compute pruning score
↓
Prune low-score Gaussians
↓
Convert compact model primitives to 3D-DoG
↓
Fine-tune recovery
↓
Control DoG density, unnecessary DoG degenerates to normal Gaussian
```

### 关键点要记

```text
这篇不是只回答“删谁”，而是同时回答：
1. 什么时候删？
2. 每次删多少？
3. 根据什么删？
4. 删完后少量 primitive 怎样恢复细节？
```

### 实验要记

```text
关注：
Gaussian count reduction
Model size
FPS
PSNR / SSIM / LPIPS
不同剪枝率下质量什么时候明显下降
```

### Ablation 结论

- scheduler 能避免过早/过度剪枝。
- 更合理的 pruning score 能保护重要细节。
- 3D-DoG 对 aggressive pruning 后的边缘和高频细节恢复很关键。

## 05. Improving Densification in 3D Gaussian Splatting for High-Fidelity Rendering

来源：[CVPR 2026 Findings Open Access](https://openaccess.thecvf.com/content/CVPR2026F/html/Deng_Improving_Densification_in_3D_Gaussian_Splatting_for_High-Fidelity_Rendering_CVPRF_2026_paper.html) ｜ [Official Code / Improved-GS](https://github.com/XiaoBin2001/Improved-GS)

### 基本信息

```text
年份/会议：CVPR 2026 Findings
所属分类：D / E / G
方法阶段：训练中 densification 改进
对我重要性：★★★
```

`Improved-GS` 是这篇论文的官方代码仓库名称，不是一篇需要重复建卡的新论文。代码中的 EAS、LAS、RAP、Growth Control / Multi-view Update 分别对应下述 densification 与过拟合控制模块。

### 解决的问题

原始 3DGS 的 densification 主要依赖 2D view-space gradient 来决定 clone / split。这个策略容易：
- 漏掉边缘和高频区域；
- split 方式随机，破坏几何；
- Gaussian 数量增长过快；
- 训练后期过拟合单视角。

### 核心方法

1. Edge-Aware Score
   - 用 Laplacian edge map 找图像边缘。
   - Gaussian 如果投影到边缘像素且贡献大，就更应该 split。

2. Absolute Gradient
   - 避免正负梯度抵消。
   - 更真实地反映某个区域是否还存在重建误差。

3. Long-Axis Split
   - 沿 Gaussian 最长轴分裂。
   - 比随机 split 更符合原始椭球几何，减少扰动。

4. Recovery-Aware Pruning
   - opacity reset 后观察哪些 Gaussian 恢复慢。
   - 恢复慢的点更可能是 floater / artifact，优先剪掉。

5. Growth Control
   - 给 Gaussian 数量增长设置预算曲线。
   - 防止训练早期点数爆炸。

6. Multi-view Update
   - densification 后期用多视角更新，增强泛化。

### Pipeline

```text
Train 3DGS
↓
Compute absolute gradient
↓
Compute edge-aware score from 2D edge map and Gaussian contribution
↓
Select candidate Gaussians
↓
Apply long-axis split
↓
Use recovery-aware pruning to remove unreliable Gaussians
↓
Control Gaussian growth budget
↓
Multi-view update after densification stage
```

### 最重要的迁移点

```text
Edge-Aware Score 可以从 densification 迁移到 pruning：
边缘贡献大的 Gaussian 不应该轻易剪。
```

### 实验要记

```text
关注：
PSNR / SSIM / LPIPS
Gaussian 数量
训练开销
是否有额外 inference overhead

核心结论：
在更少 Gaussians 下提升 rendering fidelity，
且不增加额外训练或推理开销。
```

### Ablation 结论

- Edge-Aware Score 提升细节和 LPIPS。
- Long-Axis Split 提升几何稳定性。
- Recovery-Aware Pruning 减少 floater。
- Growth Control 避免过早过密。

## 06. Mobile-GS: Real-time Gaussian Splatting for Mobile Devices

来源：[GitHub / arXiv 信息](https://github.com/xiaobiaodu/Mobile-GS)

### 基本信息

```text
年份/会议：ICLR 2026
所属分类：M / C / Q / R
方法阶段：移动端渲染系统 + 压缩
对我重要性：★★☆
```

### 解决的问题

3DGS 在桌面 GPU 上能实时，但移动端受限于：
- depth sorting 成本高；
- alpha blending 难并行；
- Gaussian 数量多；
- 属性存储和显存带宽高。

### 核心方法

1. Depth-aware Order-independent Rendering
   - 传统 3DGS 需要严格按深度排序再 alpha blending。
   - Mobile-GS 试图消除或弱化排序瓶颈，提高移动端并行效率。

2. Quantization
   - 压缩 Gaussian 属性，降低内存和带宽。

3. Contribution-based Pruning
   - 减少 Gaussian 数量。
   - 删除视觉贡献低的 primitive。

4. Mobile-friendly system design
   - 目标不是只让文件小，而是真正在手机/边缘设备上跑得快。

### Pipeline

```text
Train / pretrain compact 3DGS
↓
Prune low-contribution Gaussians
↓
Quantize Gaussian attributes
↓
Use order-independent rendering to reduce sorting bottleneck
↓
Deploy on mobile GPU
```

```text
重点指标：
mobile FPS
model size
PSNR / SSIM / LPIPS
device type
rendering resolution
```

## 12. HumanSplatHMR: Closing the Loop Between Human Mesh Recovery and Gaussian Splatting Avatar

来源：[arXiv](https://arxiv.org/abs/2605.02784)

### 基本信息

```text
年份：2026 arXiv
所属分类：H / G / Sem
方法阶段：HMR + Gaussian Avatar 联合优化
对我重要性：★★☆
```

### 解决的问题

Human Mesh Recovery 关注人体 mesh / pose 准确，但渲染外观不一定好；Gaussian Avatar 关注渲染质量，但常把 pose 和 appearance 分开处理，依赖预先准确的 SMPL/SMPL-X。如果初始人体姿态估计有误，Avatar 会被错误 pose 带偏；如果 Gaussian 太自由，又可能脱离人体 mesh，在训练视角上过拟合。

### 核心方法

1. Closing the Loop
   - 不把 HMR 输出的 SMPL pose 当作固定输入。
   - 通过 differentiable rendering 的 photometric / segmentation / depth loss 反向优化 pose 和 global position。

2. CAMEL: Cloth-Aware Mesh-Embedded Loss
   - 让 Gaussian 和人体 mesh 保持松耦合。
   - 不是强迫所有 Gaussian 死贴 mesh，也不是完全自由脱离。
   - 允许衣服厚度和局部非刚性，但保持几何一致。

3. Mesh Coverage Loss
   - 保证人体 mesh 被 Gaussian 覆盖，避免某些身体区域缺点。

4. Gaussian Flatness Regularization
   - 鼓励 Gaussian 更扁、更贴近人体表面。

5. Surface Alignment Loss
   - 鼓励 Gaussian 最小轴和 mesh normal 对齐。

6. Depth and Mask Supervision
   - 使用 UniDepthV2 提供 metric depth。
   - 使用 SAMv2 生成人体 mask。
   - 用 depth/mask 帮助 pose 和 geometry 对齐。

### Pipeline

```text
Input monocular RGB video
↓
HMR2.0 estimates initial SMPL pose
↓
SAMv2 gives human mask
↓
UniDepthV2 gives metric depth
↓
Initialize Gaussians on / near SMPL mesh
↓
Render color and depth through differentiable renderer
↓
Backprop photometric + segmentation + depth + CAMEL losses
↓
Jointly refine SMPL pose/global position and Gaussian attributes
↓
Output better mesh pose and higher-quality avatar rendering
```

### 实验要记

```text
Datasets：
H36M, 3DPW, NeuMan

Metrics：
SMPL accuracy: MPJPE, PA-MPJPE, V2V
Rendering: PSNR, SSIM, LPIPS

重要结论：
相比只用 HMR 或 decoupled avatar，HumanSplatHMR 同时提升 pose alignment 和 novel-view rendering。
```

### Ablation 结论

- 不优化 SMPL，pose 和渲染都会受影响。
- 去掉 depth loss，global 3D alignment 变差。
- learnable skinning weights 可提高渲染，但可能让 Gaussian 脱离 mesh，损害 SMPL accuracy。
- CAMEL 在 rendering quality 和 SMPL accuracy 之间取得更好平衡。

## 13. DNGaussian: Optimizing Sparse-View 3D Gaussian Radiance Fields with Global-Local Depth Normalization

来源：[CVPR 2024 Open Access](https://openaccess.thecvf.com/content/CVPR2024/html/Li_DNGaussian_Optimizing_Sparse-View_3D_Gaussian_Radiance_Fields_with_Global-Local_Depth_CVPR_2024_paper.html) ｜ [Official Code](https://github.com/Fictionarry/DNGaussian)

### 基本信息

```text
年份/会议：CVPR 2024
所属分类：Dep / G / L
方法阶段：少视角 3DGS 训练中的深度正则化
对我重要性：★★★★★
```

### 解决的问题

输入视角变少后，RGB 重建损失不足以约束真实几何，同一组训练图像可能对应多种错误的 Gaussian 深度分布。普通 3DGS 仍可能在训练视角上拟合颜色，但在新视角出现漂浮点、空洞和几何错位。

直接把单目伪深度施加到 Gaussian 的全部属性也不理想。伪深度通常较平滑且只有相对尺度，如果让 scale 和 rotation 一起强行拟合它，Gaussian 会牺牲原本用于表达细纹理的形状，导致外观变糊。

### 核心方法

1. Shape Freezing
   - 深度正则化时冻结 scale `s` 和 rotation `q`。
   - 将位置 `mu` 与 opacity `alpha` 视为几何重塑的主要变量。
   - 目的不是让椭球形状迎合粗糙深度，而是移动 Gaussian 中心、调整空间占据。

2. Hard Depth Regularization
   - 渲染 hard depth 时，把沿射线的 Gaussian 使用统一较大 opacity `tau`。
   - 前面的 Gaussian 会迅速遮挡后面的 Gaussian，因此 hard depth 主要由最近表面决定。
   - 此阶段重点更新 Gaussian center，使位置错误的 primitive 真正移动，而不能靠变透明或变形逃避约束。

3. Soft Depth Regularization
   - 普通 alpha blending 的深度是多个 Gaussian 按 `T_i alpha_i` 加权后的 soft depth。
   - 仅修正最近表面仍可能留下半透明或空心结构，所以 soft 阶段冻结 center，重点调整 opacity。
   - Hard 管“表面位置”，Soft 管“沿射线的真实占据与透明度”，两者作用不同。

4. Global-Local Depth Normalization
   - 单目深度没有可靠绝对尺度，不能直接与渲染深度逐值比较。
   - Local normalization 在小 patch 内用该 patch 的均值和标准差归一化，放大小范围深度起伏。
   - Global normalization 保留全图尺度信息，防止模型只关注局部变化而丢掉整体形状。
   - 两种归一化共同用于 hard / soft depth loss。

### Pipeline

```text
Sparse posed RGB images
↓
Use a pretrained monocular depth estimator to obtain pseudo depth
↓
Initialize and optimize 3D Gaussians with RGB reconstruction loss
↓
Freeze Gaussian scale and rotation during depth regularization
↓
Hard depth loss: mainly move Gaussian centers
↓
Soft depth loss: mainly adjust opacity while center is fixed
↓
Apply local and global depth normalization
↓
Continue RGB/depth joint optimization and render novel views
```

### 关键 score / 公式要记什么

```text
Soft depth:
D_soft(p) = Σ_i distance(mu_i, camera) × alpha_i(p) × T_i(p)

Local normalization:
D_LN(x) = [D(x) - mean(D(P))] / [std(D(P)) + eps]

Global normalization:
D_GN(x) = [D(x) - mean(D(P))] / [std(D_image) + eps]
```

理解重点：
- `Hard depth` 强调最前面的表面，用于修正 center。
- `Soft depth` 保留真实 alpha compositing，用于修正 opacity 与占据。
- `Local` 让细小深度变化不会被大尺度范围淹没。
- `Global` 维持整体几何关系。
- depth 在这里是训练 loss，不是 edge detector，也不是直接的 pruning score。

### 实验要记

```text
数据集：LLFF / DTU / Blender
输入：3 / 6 / 9 views 等 sparse-view 设置
指标：PSNR / SSIM / LPIPS / training time / rendering speed / memory

论文主张：
相对当时的 sparse-view radiance-field baselines，
训练时间约减少 25x，渲染速度可超过 3000x，
同时保持有竞争力的少视角新视角合成质量。
```

注意：这些倍率的比较对象主要是 sparse-view NeRF 类方法，不能直接解释成比 FastGS 快 25 倍或 3000 倍。

### Ablation 结论

- 只使用普通的全参数 depth loss 容易损伤纹理，shape freezing 很关键。
- Hard depth 能推动错误位置的 Gaussian 移动，但单独使用不能充分修复透明度和空洞。
- Soft depth 补充真实 compositing 下的 opacity 约束。
- Local normalization 对局部几何细节重要，Global normalization 负责整体结构；二者是互补关系。

### 局限

- 依赖单目深度估计质量，反光、透明和纹理缺失区域可能产生错误监督。
- 研究对象是静态 sparse-view 场景，不直接解决动态视频。
- 动态视频中不同帧的单目深度可能有独立的 scale/shift 漂移，不能逐帧直接套用。
- 额外深度模型推理和 depth loss 也会增加预处理与训练成本。

## 14. Perceptual-GS: Scene-adaptive Perceptual Densification for Gaussian Splatting

来源：[arXiv](https://arxiv.org/abs/2506.12400) ｜ [Official Code](https://github.com/eezkni/Perceptual-GS)

### 基本信息

```text
年份/会议：ICML 2025
所属分类：D / Per / E / L
方法阶段：训练中 perception-aware densification
对我重要性：★★★★☆
```

### 解决的问题

vanilla 3DGS 主要按 view-space position gradient 增密，无法显式区分“人眼敏感的局部结构”和“视觉上不重要的平滑区域”。结果可能是简单区域 Gaussian 冗余，而树叶、道路纹理、细边界等区域仍然模糊。

直接使用 Sobel 响应强度也有问题：强轮廓数值很大，较弱但人眼可见的细纹理容易被掩盖。因此论文不是简单把 edge magnitude 加到 gradient，而是先建立可学习的 3D perceptual sensitivity 表示。

### 核心方法

1. Perceptual Sensitivity Extraction
   - 对训练 RGB 图像使用 Sobel 提取梯度幅值。
   - 用阈值把响应二值化，表达“能否被感知”，降低绝对边缘强度差异的影响。
   - 再通过平均池化和阈值平滑，得到每个视角的 sensitivity map。

2. Dual-branch Rendering
   - 每个 Gaussian 新增一个可学习 sensitivity 参数 `epsilon_i`。
   - RGB branch 正常渲染颜色；sensitivity branch 用同一组 alpha blending 权重渲染 sensitivity。
   - 用 BCE 让渲染 sensitivity map 对齐预计算的二值 map，使 2D 感知信息真正落到 3D primitive 上。

3. Perceptual Sensitivity-guided Densification
   - warm-up 后将 Gaussian 分为 high、medium 和 low sensitivity。
   - high 表示持续位于人眼敏感区域；medium 往往表示一个 Gaussian 跨多个不同 sensitivity 区域，单个 primitive 表达范围过大。
   - 还要求 Gaussian 的最大多视角 rendering weight 超过阈值，避免只凭 sensitivity 无限制加点。
   - 高/中 sensitivity 点被额外 densify；大多数情况优先 split，只有低 scene-sensitivity 场景中的 high 组允许 clone。

4. Scene-adaptive Depth Reinitialization
   - 统计 warm-up 后“大 scale 且 medium sensitivity”的比例 `gamma`。
   - 比例高说明 SfM 初始点云可能太稀疏，较大的 Gaussian 正在跨区域勉强覆盖。
   - 仅在 `gamma` 超过阈值时触发 depth reinitialization，避免所有场景都付出相同代价。

5. Opacity Decline for Clone
   - vanilla clone 会复制 opacity，使同一区域总 opacity 突然升高，冗余 child 之后更难被剪掉。
   - 论文在 clone 时降低 parent/child opacity，尤其更强地压低原本低 opacity 的 clone，让无用点更容易被后续 pruning 清除。

### Pipeline

```text
Training RGB views
↓
Sobel gradient → threshold enhancement → pooling/smoothing
↓
Precompute binary perceptual sensitivity maps
↓
Warm-up 3DGS with RGB branch + sensitivity branch
↓
Learn one sensitivity value for each Gaussian
↓
Select high/medium sensitivity Gaussians with rendering-weight constraint
↓
Scene-adaptive clone or split + opacity decline
↓
If sparse-initialization indicator is high, apply depth reinitialization
↓
Continue ordinary 3DGS optimization and pruning
```

### 关键 score / 公式要记什么

```text
Sensitivity rendering:
R_S^v(u) = Σ_i w_i^v(u) × sigmoid(epsilon_i)

Training loss:
L = (1 - lambda_S) L_RGB + lambda_S L_BCE(sensitivity)

Candidate constraint:
G_D = {high or medium sensitivity Gaussians}
      ∩ {max multi-view rendering weight > threshold}
```

Opacity decline 的核心约束：两个重叠 clone 的合成 opacity 应等于一个主动降低后的目标值，而不是简单复制后使区域更不透明。

### 实验要记

```text
数据集：Mip-NeRF 360 / Tanks & Temples / Deep Blending / BungeeNeRF
关注：PSNR / SSIM / LPIPS / Gaussian 数量 / FPS

Mip-NeRF 360 平均消融表：
3DGS*：27.71 PSNR / 0.826 SSIM / 0.202 LPIPS / 3.14M
Full： 28.01 PSNR / 0.839 SSIM / 0.172 LPIPS / 2.69M
```

这组数字支持的是“在论文协议下获得更好的质量-点数平衡”，不能直接推成在 FastGS 的 100 秒预算下仍有相同收益。

### Ablation 结论

- 去掉 perception-oriented enhancement 后，质量接近 vanilla 3DGS，说明不能只依赖原始 Sobel 强度。
- 去掉 high-sensitivity densification 后性能明显下降，high 组是主要质量来源。
- 去掉 medium-sensitivity densification 后仍优于 baseline，但细节恢复变弱。
- 去掉 scene-adaptive depth reinitialization 的影响较小，说明它是场景条件模块而非核心主因。
- Dual-branch rendering 不只是传递标签，也会抑制 low-sensitivity 区域的 gradient 与 densification。

### 局限

- sensitivity 主要是图像感知先验，不等同于真实 3D geometry boundary。
- 二值阈值、high/medium 分组、事件间隔等超参数较多。
- 额外 sensitivity 参数和渲染分支增加训练复杂度。
- 论文主要验证静态场景；动态视频中的纹理运动、遮挡和时间闪烁尚未处理。

## 15. PSCD-GS: Role-Aware Perception-Structure Collaborative Densification for 3D Gaussian Splatting

来源：用户提供的本地 PDF `PSCD_GS_for_3D_Gaussian_Splatting__1_ (1).pdf`

### 基本信息

```text
年份/会议：2026 manuscript；PDF 未标明正式录用 venue，引用时需再次核验
所属分类：D / Per / Str / V
方法阶段：训练中 role-aware densification
对我重要性：★★★★☆
```

### 解决的问题

只用 gradient 只能说明“当前优化压力大”，不能说明欠拟合来自纹理、结构边界还是二者共同作用。只加一个 perceptual 或 edge score 也不足以回答 densification 的三个不同问题：

```text
1. 哪个 Gaussian 需要新增容量？
2. 新增容量应该 clone 还是 split？
3. split 后的 child 应该放在哪里？
```

PSCD-GS 因此把 perception 与 structure 分开建模，再用连续角色同时协调三个决策。

### 核心方法

1. Perceptual Evidence `P`
   - 用冻结的 ImageNet VGG-16 / LPIPS 特征提取多尺度 feature variation。
   - 得到感知响应强度图和主要图像方向 tensor。
   - 这部分更关注纹理与外观变化，训练前可预计算。

2. Structural Evidence `Q`
   - 由 luminance gradient 与当前渲染 `log-depth gradient` 共同形成单视角结构响应。
   - 把像素反投影到相邻相机，比较深度与结构响应的一致性。
   - 多视角一致性在这里是 reliability gate：它决定单视角边界可信多少，而不是凭空制造结构分数。

3. Contribution-weighted Gaussian Aggregation
   - 使用 renderer 的真实贡献 `w_i^v(u)=T_i^v(u) alpha_i^v(u)`，把 2D P/Q map 聚合到每个 Gaussian。
   - 再根据跨视角支持数和方差衰减“只在一个弱视角出现”或“多视角互相矛盾”的证据。
   - 用随 densification event 更新的分位数范围校准为 `P_i, Q_i ∈ [0,1]`。

4. Continuous Perception-Structure Roles
   - 分别将 `P_i`、`Q_i` 经过 sigmoid，得到软 membership。
   - 四种角色为 co-dominant、perception-dominant、structure-dominant、low-response。
   - 它们不是硬语义标签；同一个 Gaussian 可以在训练中连续改变角色。

5. Role-conditioned Densification
   - Candidate priority：保留原始 gradient demand，再让 P/Q evidence 提供有限 bonus，并受每次净增长预算约束。
   - Clone-or-split：perception-dominant 更偏向 clone，structure-dominant 更偏向 split；大 scale 仍强制 split。
   - Split placement：把多视角 2D 响应方向通过 projection Jacobian 提升到 Gaussian 支持域中的 3D 方向，再沿可靠方向对称放置 children；置信度不足时回退到主轴或 vanilla 随机采样。

### Pipeline

```text
Precompute VGG perceptual maps, image boundaries and camera-neighbor graph
↓
Ordinary 3DGS training accumulates view-space gradient
↓
At each densification event, render current depth
↓
Build perceptual P maps and multi-view reliable structural Q maps
↓
Aggregate P/Q to Gaussians with T × alpha contribution
↓
Compute four continuous role memberships
↓
Fixed growth budget: select candidates
↓
Role-conditioned clone/split decision
↓
Confidence-aware child placement
↓
Return to original optimization, pruning and opacity-reset loop
```

### 关键 score / 公式要记什么

```text
Per-pixel contribution:
w_i^v(u) = T_i^v(u) × alpha_i^v(u)

Gaussian-level evidence:
x_i^{X,v} = Σ_u w_i^v(u) X^v(u) / [Σ_u w_i^v(u) + eps]
where X is perceptual map A or structural map B

Candidate priority:
D_i = G_i + alpha_bonus × (1 - G_i) × S_i
```

其中 `G_i` 是由原始 view-space gradient 得到的 optimization demand，`S_i` 是由连续 P/Q 角色得到的 evidence bonus。这里没有用 P/Q 替代 gradient，而是让证据在受控范围内重新排序候选。

### 实验要记

```text
数据集：Mip-NeRF 360 / Deep Blending / Tanks & Temples
指标：PSNR / SSIM / LPIPS / final Gaussian count

Full model 的三组 benchmark-level ablation 数值：
Mip-NeRF 360：28.2439 / 0.8396 / 0.1814
Deep Blending：30.2961 / 0.9184 / 0.2243
Tanks & Temples：24.5968 / 0.8815 / 0.1407
顺序：PSNR / SSIM / LPIPS
```

论文报告 Mip-NeRF 360 约 2.8M Gaussians，并强调质量导向的受控增长；它不是以最少点数或最快训练为第一目标。

### Ablation 结论

- Mip-NeRF 360 上，去掉 joint candidate selection 对 PSNR/SSIM 影响最大；去掉 perceptual branch 对 LPIPS 影响明显。
- Deep Blending 同样依赖 perceptual evidence 与 joint candidate selection。
- Tanks & Temples 上 structural branch 最重要，符合其物体轮廓、遮挡边界和细结构较多的特点。
- 去掉 soft role、role-adaptive clone/split、role-guided placement 都会退化，说明“在哪加、怎么加、加到哪”是连续但不同的决策。

### 局限

- VGG 特征、深度刷新、多视角重投影和 contribution tensor 统计增加训练开销，PDF 未把该开销与 FastGS 级别的总训练时间系统比较。
- 依赖当前渲染深度和跨视角对应；少视角、反光、运动与遮挡会削弱结构 reliability。
- 主要验证静态场景，动态和在线重建尚未验证。
- soft role 与决策仍含多组固定阈值，跨场景鲁棒性需要额外复核。
- 当前 PDF 的正式发表状态不明确，投稿引用前必须核验最新版本。

## 16. HyperGaussians: High-Dimensional Gaussian Splatting for High-Fidelity Animatable Face Avatars

来源：[CVPR 2026 Paper](https://openaccess.thecvf.com/content/CVPR2026/html/Serifi_HyperGaussians_High-Dimensional_Gaussian_Splatting_for_High-Fidelity_Animatable_Face_Avatars_CVPR_2026_paper.html) ｜ [Project Page](https://gserifi.github.io/HyperGaussians/) ｜ [Official Code](https://github.com/gserifi/HyperGaussians)

### 基本信息

```text
年份/会议：CVPR 2026
所属分类：ND / Dyn / H / G
方法阶段：动态 Avatar 的 primitive 表示层
对我重要性：★★★★★
```

### 解决的问题

许多人脸 Avatar 方法使用 MLP 根据表情或姿态直接预测每个 Gaussian 的 position、scale、rotation offset。这样的映射缺少每个局部 Gaussian 自己的上下文，容易把眼睛高光、眼镜反射、牙齿缝隙、皱纹和眼睑闭合等高频动态效果平均掉。

简单加宽或加深 deformation MLP 不一定能解决问题，而且会显著降低 FPS。HyperGaussians 的思路是从 primitive 参数化本身增加表达力：让 Gaussian 属性与一个局部 latent 共同组成高维联合 Gaussian，再根据当前表情生成的 latent 对属性做条件化。

### 核心方法

1. Attribute-Latent Joint Gaussian
   - 将某一类 3DGS 属性 `A` 与局部 latent `z` 建模为联合多元 Gaussian。
   - 属性可以分别是 position offset、scale offset 或 rotation offset。
   - 联合 covariance 的交叉块学习“latent 怎样影响该属性”。

2. Conditional Gaussian to Ordinary 3DGS
   - 当前表情/姿态经过原 avatar 网络，不再直接输出属性 offset，而是输出 per-Gaussian latent `z`。
   - 对联合 Gaussian 计算 `p(A | z)`，取条件均值作为当前帧的 position/scale/rotation offset。
   - 条件化后仍得到普通 3D Gaussian，所以后端可继续使用标准 differentiable rasterizer。

3. Separate Conditional Position, Scale and Rotation
   - 与早期 NDGS 主要依赖 position 的条件分布不同，HyperGaussians 分别让 position、scale、rotation 随 latent 改变。
   - 这使 Gaussian 在动态形变中不仅能移动，还能旋转和缩放，更适合眼睑、嘴部和皱纹等非线性局部变化。

4. Bayesian Interpretation and Uncertainty
   - 条件均值等价于 Gaussian 条件分布的 MAP 解。
   - 条件 covariance 不直接参与 splatting，但可解释为属性的不确定性。
   - 注意：论文证明了这种不确定性可被计算，不等于已经用它完成 pruning。

5. Inverse Covariance Trick
   - 朴素条件化需要存储和求逆大的 latent covariance block `Sigma_bb`，latent 维数高时很贵。
   - 论文改用 precision matrix `Lambda = Sigma^{-1}`，只需处理较小的属性 block `Lambda_aa` 和交叉 block `Lambda_ab`。
   - 复杂度从 `O(n^3 + m n^2)` 降为 `O(m^3 + m^2 n)`；结合 Cholesky 还可进一步降低。

6. Plug-in Integration
   - 在 FlashAvatar 中，把 deformation MLP 的 `delta position/rotation/scale` 输出改为 latent 输出。
   - 在 GaussianHeadAvatar 中做相同替换。
   - 其余训练 loss、renderer 和大部分超参数保持不变，用来证明提升来自 primitive 表示，而非整体重写网络。

### Pipeline

```text
Monocular or multi-view face video
↓
Track 3DMM/FLAME pose and expression; attach Gaussians to mesh
↓
Avatar deformation network predicts a local latent z for every Gaussian
↓
Condition high-dimensional joint Gaussians on z
↓
Obtain ordinary 3D position / scale / rotation offsets from conditional means
↓
Construct current-frame 3D Gaussians
↓
Use standard Gaussian splatting and original avatar losses
```

### 关键 score / 公式要记什么

```text
Standard conditional mean:
mu_{a|b} = mu_a + Sigma_ab Sigma_bb^{-1} (z - mu_b)

Inverse covariance trick:
mu_{a|b} = mu_a - Lambda_aa^{-1} Lambda_ab (z - mu_b)

Conditional covariance:
Sigma_{a|b} = Lambda_aa^{-1}
```

最容易混淆的点：
- 这里的高维 covariance 描述“属性和 latent 的联合关系”。
- 渲染时的 3D spatial covariance 仍由条件化后的 scale 与 rotation 构造。
- 二者不是同一张 covariance matrix。

### 实验要记

```text
数据：6 个数据集、29 个 subjects
Monocular：19 subjects，512×512，FlashAvatar baseline
Multi-view：10 subjects，NeRSemble，GaussianHeadAvatar baseline

FlashAvatar → HyperGaussians：
PSNR 29.43 → 29.99
SSIM 0.9466 → 0.9510
LPIPS 0.05107 → 0.04978

GaussianHeadAvatar → HyperGaussians：
PSNR 24.10 → 24.38
LPIPS 0.20273 → 0.19768
```

`n=8` 是论文的人脸 Avatar 推荐 latent dimension；FlashAvatar 集成后约 300 FPS。FlashAvatar 每个视频在 RTX 4090 上约 15-20 分钟，而 GaussianHeadAvatar 仍需 600K iterations、超过 2 天，说明表示层更好并不自动等于所有 baseline 都训练很快。

### Ablation 结论

- 只把 deformation MLP 加深或加宽，质量不如 HyperGaussians，FPS 还从约 300 降到 158/178。
- `n=8` 在质量、参数量和速度之间最好；更高 latent dimension 参数量继续增加，但质量不再稳定提升。
- inverse covariance trick 在 `n=8` 时将朴素条件计算内存从约 42 MB 降到 22 MB；latent 越大，节省越明显。
- 在 GaussianHeadAvatar 中额外训练时间约增加 1%，说明高效条件化确实控制住了新增开销。

### 局限

- 主要验证人脸 Avatar，有 3DMM/FLAME、mesh attachment 和可靠表情跟踪先验，不等同于无模板通用动态场景。
- 高维表示仍增加参数、显存和条件计算，只是 inverse covariance trick 大幅缓解而非消除。
- 论文重点是高保真表达，不是 pruning、densification 或训练到 100 秒。
- 条件 uncertainty 没有被论文直接用于 VCP；把它当 pruning risk 需要重新验证。

## 17. N-Dimensional Gaussians for Fitting of High Dimensional Functions

来源：[SIGGRAPH 2024 Project Page](https://sdiolatz.info/ndg-fitting/) ｜ [arXiv](https://arxiv.org/abs/2405.20067) ｜ [Official Code](https://github.com/intel/ndg-fitting)

### 基本信息

```text
年份/会议：SIGGRAPH 2024 Conference Track
所属分类：ND / Dyn / D / R
方法阶段：高维表示 + 训练中 refinement + 高维查询 culling
对我重要性：★★★★★
```

### 解决的问题

普通 3DGS 主要在 3D 空间中显式建模 geometry，再用 SH 表示视角相关颜色。若输入函数还依赖时间、视角方向、材质、粗糙度或光照位置，简单追加 feature 或使用 MLP 会带来两个问题：

- 高维 Gaussian 数量大时，逐查询评估所有 primitive 太慢；
- 维度越高，手工决定“沿哪一维 split、何时 split”越困难。

论文因此提出通用 N-D Gaussian mixture、随机投影 culling 和由 optimizer 自己激活容量的 refinement。

### 核心方法

1. Full N-D Gaussian Parameterization
   - 每个 Gaussian 有 `m ∈ R^N` 和完整 covariance `V ∈ R^{N×N}`。
   - 用 Cholesky factor `V = L L^T` 保证正定，并直接学习下三角矩阵。
   - 非对角项显式表达维度耦合，例如 position-view、position-time 或 position-material 的相关性。

2. Random-projection / LSH-inspired Culling
   - 将 query、Gaussian mean 和 covariance 投影到若干随机单位向量 `r`。
   - 若某个投影上 query 位于 Gaussian 的 3-sigma 区间之外，该 Gaussian 可被保守剔除。
   - 实现按 `16×16` tile 处理 query bounds，避免逐像素做全部高维判断。

3. Optimization-Controlled Refinement
   - 初始收敛后，每个 main Gaussian 挂一个贡献极低、相对 parent 参数化的 child。
   - child 的 mean/covariance 随 parent 一起移动，只有当前容量表达不了细节时，optimizer 才会提高 child 的 opacity/brightness 并让它与 parent 分离。
   - child 贡献超过阈值后被 materialize：parent 与 child 都成为独立 main Gaussian，并各自获得新的 dormant child。
   - 论文实现约每 300 iterations 检查一轮；opacity 应用示例阈值 0.1，brightness 应用示例阈值 0.01。

4. Parent-relative Child Geometry
   - parent covariance 为 `V_p = L L^T`。
   - child 使用局部变换 `U`：`V_c = L U (L U)^T`。
   - child mean 为 `m_c = L m_u + m_p`。
   - 这种依赖让 child 初期待在 parent 支持范围内，不会一开始就跑到无关区域重复拟合。

5. Two Applications
   - `10D+ surface radiance`：position、view、albedo、roughness 等共同作为输入，拟合复杂全局光照函数。
   - `6D volumetric radiance`：3D position + 3D view direction；给定视角后将 6D Gaussian 条件化/投影为 3D，再使用 3DGS rasterizer。

### Pipeline

```text
Normalize N-dimensional query space and initialize a small Gaussian mixture
↓
Optimize full N-D means, Cholesky factors and appearance/opacity
↓
Use random projections to cull irrelevant Gaussians per query tile
↓
After initial convergence, attach low-contribution child to each main Gaussian
↓
Optimizer raises only the children needed for missing details
↓
Materialize children that cross the contribution threshold
↓
Repeat refinement phases
↓
Evaluate directly in N-D or condition/project to 3D for splatting
```

### 关键 score / 公式要记什么

```text
N-D Gaussian:
G(x) = exp[-1/2 (x - m)^T V^{-1} (x - m)]
V = L L^T

Random projection:
q_r = q^T r
m_r = m^T r
sigma_r^2 = r^T V r

Cull when query lies outside the projected 3-sigma interval:
|q_r - m_r| > 3 sigma_r
```

阅读提醒：论文排版中的 Eq. (5) 印成了 `< 3 sigma`，但紧随其后的文字、图示和 culling 逻辑都说明应当是“落在区间外才剔除”，也就是 `>`。实现时不能照抄符号。

### 实验要记

```text
6D real-world radiance-field scenes：CD / Tools

PSNR：
CD：Ours 28.39 / 3DGS 25.76 / INGP 27.23
Tools：Ours 27.58 / 3DGS 26.32 / INGP 25.70

Gaussian count 与 Python-renderer inference：
CD：Ours 0.32M, 24.5 ms / 3DGS 1.01M, 62.92 ms
Tools：Ours 0.27M, 41.23 ms / 3DGS 1.36M, 70.57 ms
```

高维 culling 在论文的合成场景 profile 中把 brute-force inference 从约 317 ms 降到 131 ms，平均 Gaussian evaluations 从 7856 降到约 1985。这里是论文自有 Python/Taichi 实现，不能与 FastGS CUDA FPS 直接横比。

### Ablation 结论

- 3-sigma 是论文选择的质量-速度折中；继续压到 2-sigma 或 1.5-sigma 虽更快，但开始出现明显伪影。
- culling 同时减少 forward evaluation 与 backward propagation，因此训练和推理都受益。
- parent-relative child 约束很关键；无约束 child 容易离开 parent 并重复拟合。
- dormant child 让新增容量初始贡献近乎为零，避免传统突然 split 造成 loss spike。

### 局限

- 完整 N-D covariance 的参数量按 `O(N^2)` 增长。
- 高维拟合需要足够密集的训练采样；输入稀疏时更容易过拟合。
- 官方实现明确说明当前 refinement 不适合 360 度场景，依赖较好初始化或近似 front-facing capture。
- 论文展示的是视角/材质等高维函数，虽提到 time 维度，但没有直接完成通用单目动态重建。
- 其 Cholesky 表示与 FastGS 的 quaternion + scale 参数化不同，不能直接复制 child 公式。

## 18. Deformable 3D Gaussians for High-Fidelity Monocular Dynamic Scene Reconstruction

来源：[CVPR 2024 论文](https://openaccess.thecvf.com/content/CVPR2024/html/Yang_Deformable_3D_Gaussians_for_High-Fidelity_Monocular_Dynamic_Scene_Reconstruction_CVPR_2024_paper.html) ｜ [arXiv 全文](https://arxiv.org/html/2309.13101) ｜ [官方代码](https://github.com/ingra14m/Deformable-3D-Gaussians)

### 基本信息

```text
年份/会议：CVPR 2024
所属分类：动态重建 / 形变场 / 训练中加点
方法阶段：初始化 → Gaussian warm-up → 联合训练与密度控制 → 按时间渲染
对我重要性：★★★★★
```

### 解决的问题

静态 3DGS 的每个 Gaussian 固定在场景里，不能直接表达单目视频中随时间运动、变形的物体。逐帧单独训练既不能共享几何，也不容易在未见时刻插值。该论文让一套 canonical Gaussians 通过时间条件形变场生成任意时刻的 Gaussian，同时保留可微 splatting 的渲染效率。

### 核心方法

1. Canonical 3D Gaussians：维护一套可学习的标准空间 Gaussian；SfM 点云或随机点初始化，不为每一帧存一套完整独立点云。
2. Deformation MLP：将 Gaussian 的 canonical 位置与时间经 positional encoding 输入 MLP，预测位置、旋转、尺度偏移；位置输入使用 stop-gradient，避免通过该输入路径产生不受控的梯度耦合。形变后的 Gaussian 再用 3DGS rasterizer 渲染。
3. 分阶段优化：前 3k iterations 先优化 Gaussians，不训练形变场；之后联合优化 Gaussian 与形变网络，并执行自适应密度控制。这里的 densification 是沿用动态训练框架中的容量管理，不是 FastGS 的 VCD。
4. Annealing Smooth Training (AST)：训练早期在输入时间上加入逐渐衰减的扰动，鼓励相邻时刻预测平滑，后期减小扰动以保住细节；重点针对真实数据相机姿态误差引起的时间插值抖动。

### Pipeline

```text
单目动态帧 + 相机参数；SfM 点云或随机点初始化
↓
建立 canonical Gaussians
↓
前 3k 步 Gaussian warm-up
↓
给定时间 t，Deformation MLP 预测 delta-position/rotation/scale
↓
变形后 3DGS splatting → 图像损失反传
↓
联合优化、densification/pruning；训练早期使用 AST
↓
给新视角和新时刻渲染
```

### 关键 score / 公式要记什么

```text
f_theta(PE(stopgrad(x_i)), PE(t)) → (delta_x_i, delta_r_i, delta_s_i)
x_i(t) = x_i + delta_x_i(t)
```

其余旋转、尺度也作相应更新。最重要的区别是“一个跨时刻共享的 Gaussian 集合 + 每个时刻的形变”，而不是“每帧重新训练一个静态 FastGS”。单目指每个时间点通常只有一个相机观测，不等于全序列相机始终不移动。

### 实验要记

### Ablation 结论

- AST 对真实数据的时间平滑和平均质量有贡献；它不是一个新的剪枝或加点 score。
- 先 warm-up 再联合训练，使初始 canonical 表示与形变学习分阶段进行；不能把这 3k 步直接套到另一个训练总步数不同的实现。

### 局限

- 单目视频每一时刻缺少同步多视角证据，形变、几何和相机误差容易相互补偿。
- 快速非刚性运动、稀疏视角、姿态不准确时，canonical 对应关系可能不稳。
- Gaussian 容量仍会影响训练、显存与渲染；论文并未证明 FastGS VCD/VCP 可以原样移植到形变模型。

## 19. 4D Gaussian Splatting for Real-Time Dynamic Scene Rendering

来源：[CVPR 2024 论文](https://openaccess.thecvf.com/content/CVPR2024/html/Wu_4D_Gaussian_Splatting_for_Real-Time_Dynamic_Scene_Rendering_CVPR_2024_paper.html) ｜ [arXiv 全文](https://arxiv.org/html/2310.08528) ｜ [官方代码](https://github.com/BruceYounggit/4DGS)

### 基本信息

```text
年份/会议：CVPR 2024
所属分类：动态重建 / 时空编码 / 渲染加速
方法阶段：动态表示 + 时刻条件形变 + 训练与渲染
对我重要性：★★★★☆
```

### 解决的问题

动态场景需要同时表示 3D 空间和时间。只用小型 MLP 从位置、时间直接预测复杂形变，表达力有限；为每个时刻显式保存大量属性则存储昂贵。该论文将时空信息放进可查询的多分辨率特征平面，再用轻量解码器产生 Gaussian 的时变形状与运动。

### 核心方法

1. Canonical 3D Gaussians：基础仍是可光栅化的 3D Gaussian；论文标题中的“4D”主要指带时间条件的场景表示，不应误读成每个 primitive 都是完整 4D covariance Gaussian。
2. Spatial-temporal HexPlane：把 `(x,y,z,t)` 的特征分解到 `xy/xz/yz/xt/yt/zt` 六类 2D plane；多分辨率插值、聚合后取得时空特征。前三个偏空间结构，后三个携带时间变化。
3. Multi-head deformation decoder：小 MLP 将时空特征解码为位置、旋转、尺度的偏移；当前时刻的 Gaussian 再经普通 splatting 渲染。
4. 训练中的容量控制：沿 Gaussian 训练过程优化/增减 primitive，但核心创新在时空编码与形变场，不是新的 FastGS 风格多视角 densification score。

### Pipeline

```text
动态视频 + 相机；初始化 canonical 3D Gaussians
↓
查询位置 x 和时间 t 在六组多分辨率特征平面上的特征
↓
轻量 MLP 解码 delta-position/rotation/scale
↓
变形的 3D Gaussians → rasterizer → 重建损失
↓
联合优化 canonical Gaussians、HexPlane 和 decoder
```

### 关键 score / 公式要记什么

```text
h(x,t) = Aggregate_l[ Interpolate(xy,xz,yz,xt,yt,zt planes) ]
(delta_x, delta_r, delta_s) = Decoder(h(x,t))
G_i(t) = Deform(G_i, delta_x, delta_r, delta_s)
```

该式仅作理解性示意，原文特征聚合在不同尺度上含插值与乘积，不要把 `Aggregate` 当作论文精确实现公式。与 Deformable 3D Gaussians 相比，两者都有 canonical + deformation；这里多了显式时空平面特征。

### 实验要记

### Ablation 结论

- 去掉 HexPlane、只靠浅层 MLP，在论文合成数据 ablation 中 PSNR 降到 27.05，说明时空特征编码并非纯附加装饰。
- 去掉位置形变头，PSNR 为 26.67；这个 ablation 是合成数据表，不能拿去解释 Neu3D 的 31.15。
- 不同数据集使用不同训练配置、初始点云与 plane 分辨率；对比要固定协议。

### 局限

- 多相机同步视频的空间约束强于单目时序；稀疏时间/视角下可能出现相机运动与物体运动纠缠。
- HexPlane/decoder 引入训练和存储开销；是否比目标动态基线更快要在相同硬件和完整协议下重测。
- 它不直接解决 FastGS VCD 的候选排序或有限增长名额分配。

## 20. Improving Gaussian Splatting with Localized Points Management

来源：[CVPR 2025 论文](https://openaccess.thecvf.com/content/CVPR2025/html/Yang_Improving_Gaussian_Splatting_with_Localized_Points_Management_CVPR_2025_paper.html) ｜ [arXiv 全文](https://arxiv.org/html/2406.04251) ｜ [官方代码](https://github.com/Surrey-UP-Lab/GS-LPM)

### 基本信息

```text
年份/会议：CVPR 2025
所属分类：局部错误定位 / 多视角几何 / D / P
方法阶段：训练中识别 3D zone → 局部增密/校准 → 控制点数
对我重要性：★★★★★
```

### 解决的问题

传统 ADC 平均 Gaussian 的屏幕空间位置梯度，超过阈值才 clone/split；稀疏区域若根本没有 parent 就无从加点。错误高 opacity 点还可能挡住后方正确几何。简单全局降低梯度阈值又会让全场景点数膨胀。LPM 先定位“多视角都支持的渲染错误发生在哪个 3D 区域”，再只在那个区域做点管理。

### 核心方法

1. Paired error regions：比较当前渲染与真值形成误差图，在邻近视角通过 LightGlue 特征匹配找到对应的高误差 2D 区域。不是把单张图的所有高梯度/边缘都当作真实缺失几何。
2. Error-source 3D zone：将两张图的对应误差区域从各自相机投成锥形射线束，依据其交会得到空间候选，再用包围球概括成局部 zone。这里的“同一 3D 位置有跨视角证据”是关键约束。
3. Localized point addition：zone 内有 Gaussian 时局部降低 densification 的梯度阈值，补充原 ADC 可能漏掉的点；zone 空缺时论文提出直接补新 Gaussian，以解决“没有 parent 无法 split”。这两种情形不能混成简单候选重排。
4. Local opacity reset：对 zone 前方可能遮挡该区域、且 opacity 过高的点定点重置透明度，让后续优化重新决定遮挡关系；不是全局重置所有点。
5. Density-aware pruning：在局部补点后按密度/opacity 控制冗余增长，避免用增点换质量却让点数无限上涨。

### Pipeline

```text
正常训练、渲染训练视角并形成 error map
↓
相邻视角匹配对应的高误差区域
↓
2D 误差区域反投影 → 多视角交会 → 3D error zone
↓
zone 内有点：局部放宽 densification 阈值，clone/split
zone 内无点：尝试显式补点
↓
重置 zone 前方错误高-opacity 点
↓
继续优化，并用 density-aware pruning 抑制点数增长
```

### 关键 score / 公式要记什么

```text
原始 ADC：平均 image-space position gradient > 全局阈值 → 加点
LPM：先确定由跨视角对应误差支持的 3D zone；
     再在 zone 内放宽阈值 / 补空区点 / 校正前方 opacity。
```

理解重点：它主要改变“哪里需要操作”和“区域内做什么”，不是提出一个全场统一的新 Gaussian importance score。`error map` 本身只能说明渲染不匹配；跨视角对应与空间交会才提高了几何可信度。

### 实验要记

### Ablation 结论

- Playroom 的 full LPM PSNR 30.22；去掉 point addition 为 30.10，去掉 opacity reset 为 30.07，说明两类操作不等价。
- Truck 的 full LPM LPIPS 0.154，去掉 reset 后为 0.144（更低），说明局部重置并非每个场景、每个指标都占优。
- 全局降低梯度阈值会增长更多点；应同时报告点数、训练时间和质量，不能只看 PSNR。

### 局限

- 跨视角特征匹配、误差区域配对及反投影可能在低纹理、透明体、遮挡、运动物体或单目连续帧上失效。
- 单目视频相邻帧并非“同一时刻的两个相机”；不经运动补偿直接三角化，可能把时间变化错当空间错误。
- 论文中区域构造和公开实现的局部边界表达不一定完全一致；复现时需逐项核对代码路径。
- 对 FastGS 的训练时间和固定 densification quota 的兼容性须单独验证。

## 21. Steepest Descent Density Control for Compact 3D Gaussian Splatting (SteepGS)

来源：[CVPR 2025 论文](https://openaccess.thecvf.com/content/CVPR2025/html/Wang_Steepest_Descent_Density_Control_for_Compact_3D_Gaussian_Splatting_CVPR_2025_paper.html)

### 基本信息

```text
年份/会议：CVPR 2025
所属分类：训练中增密 / 损失感知 density control / 紧凑表示
方法阶段：候选统计 → split 决策与方向 → 常规优化
对我重要性：★★★★☆
```

### 解决的问题

位置梯度大只说明移动当前 Gaussian 有利，不能说明新增 child 比移动 parent 更有利。传统 ADC 易增长冗余点；SteepGS 研究“是否存在因分裂新自由度而降低损失的局部方向”。

### 核心方法

1. 将 parent/child 的共同位移与 child 相对平均参数的分散位移分开，避免把普通位置更新误认为 split 收益。
2. 从 Gaussian 响应的损失梯度与响应的二阶导数组合出 splitting matrix；它刻画局部的分裂方向，不是 Gaussian 形状的协方差矩阵。
3. 若最小特征值为负，局部二阶近似中存在下降的相对分散方向；对应特征向量给出候选方向。论文还分析两个等权、反向 child 的受限理想动作。
4. 用可累计的每点矩阵估计使训练期判断可计算。公开代码中的 clone/split、opacity 和预算细节不能直接等同于理论最优解。

### Pipeline

```text
正常渲染与反传 → 累计梯度和 splitting-matrix 统计
→ density-control event 求最小特征对 → 筛 parent、安排 child
→ 常规剪枝与后续优化
```

### 关键 score / 公式要记什么

```text
lambda_min(S) < 0：局部二阶模型存在有利的相对分裂方向。
v_min(S)：该局部模型给出的分裂方向。
S != Gaussian covariance；S != 完整 loss Hessian。
```

负特征值是局部近似条件，不保证远期测试质量、训练速度或最终 FPS。

### 实验要记

论文 Mip-NeRF 360 表中，3DGS 为 3.339M 点、PSNR 29.037、SSIM 0.872、LPIPS 0.183；SteepGS 为 1.606M 点、28.734、0.857、0.211。支持“明显减点”，但这组质量指标不应写成全面提升。

### Ablation 结论

精读笔记未核到能独立量化矩阵筛选、方向与 opacity 三者贡献的完整模块消融；不能凭整体对比给每一项分配收益。

### 局限

需要额外导数/矩阵统计及实现核对。局部二阶预测与最终 alpha 合成、优化轨迹不等价；接到 FastGS 还需测 event 时间与 renderer 接口成本。

## 22. Faster 3D Gaussian Splatting Convergence via Structure-Aware Densification (SAD-GS)

来源：[SIGGRAPH 2026 项目](https://vcai.mpi-inf.mpg.de/projects/SAD-GS/)

### 基本信息

```text
年份/会议：SIGGRAPH 2026 Conference Track（不是 CVPR 2026）
所属分类：结构尺度感知增密 / 短训练收敛
方法阶段：训练前多尺度图像统计 + 训练中增密
对我重要性：★★★★★
```

### 解决的问题

只看位置梯度，可能不断小步 split，却未判断现有 Gaussian 投影尺寸与图像局部细节尺度是否匹配。高频细节所需的细粒度点因而出生较晚，短训练收敛慢。

### 核心方法

1. 对 GT 图像作多尺度结构分析，用图像梯度、尺度能量和结构张量估计局部有效波长。这个量是二维细节尺度代理，不是真实表面法线或深度。
2. 把 Gaussian 三个局部轴投影到相机图像，分别计算投影轴长与局部波长之比 eta；eta 大表示该轴相对图像细节过粗。
3. 统计多个有效观测中的高响应比例，以减轻单视角纹理的偶然影响；仍要区分“图像结构支持”与“三维同表面已验证”。
4. 按每轴 eta 决定细分份数并规则放置 child，同时配套尺度、训练日程等调整。论文方法并非只换一个 score，公开代码与正文某些阈值/统计细节有差异。

### Pipeline

```text
GT 多尺度结构统计 → 局部细节尺度代理
→ parent 三轴投影长度 / 细节尺度 = eta
→ 多观测门控 → 每轴细分数 → child 网格放置与缩放
→ 继续训练、剪枝
```

### 关键 score / 公式要记什么

```text
eta_k = 第 k 条 Gaussian 投影轴长（像素）/ 局部细节尺度（像素）
n_k = ceil(sqrt(eta_k))（论文相关设置；实现需核版本）
```

`eta` 是尺度不匹配信号，不等于 residual、重要性或必须 split 的充分条件；`n_k` 增大还会直接增加点数。

### 实验要记

Mip-NeRF 360 表中 FastGS-Base 为 143.7 s、PSNR 27.55、SSIM 0.797、LPIPS 0.261、0.40M 点；SAD-GS 为 52.96 s、27.25、0.821、0.197、4.05M 点。短训练/感知指标有优势，但点数大幅增加且 PSNR 更低；不是直接紧凑化或纯渲染加速结论。两行还涉及训练日程等差别，不能当作 FastGS 上单一模块消融。

### Ablation 结论

阅读正文与补充材料的结构分析、观测门控、分裂设置及同点数比较；整体收益还混有增长剂量和训练配置，单靠主表无法归因。记录质量时必须并列点数、时间与显存/FPS。

### 局限

二维高频可来自纹理/噪声，不保证是三维缺容量；child 数量可能膨胀。动态物体的跨时观测还需要先验证表面对应。

## 23. GS²: Graph-based Spatial Distribution Optimization for Compact 3D Gaussian Splatting

来源：[CVPR 2026 论文](https://openaccess.thecvf.com/content/CVPR2026/html/Yang_GS2_Graph-based_Spatial_Distribution_Optimization_for_Compact_3D_Gaussian_Splatting_CVPR_2026_paper.html)

### 基本信息

```text
年份/会议：CVPR 2026
所属分类：紧凑表示 / 场景级停止增密 / 渐进剪枝 / 恢复
方法阶段：增密停止 → opacity 剪枝 → 剪后空间优化
对我重要性：★★★☆
```

### 解决的问题

继续增密并不总能改善收益；激进剪枝后，保留点的空间覆盖和邻域关系也会被破坏。只 fine-tune 原有属性可能难恢复结构。

### 核心方法

1. 用 ELBO-inspired 的拟合误差与复杂度代理监测训练，以 EMA/窗口变化判定何时停止增长；这是场景级时机判据，不是逐 Gaussian 的剪枝分数。
2. 加 opacity 正则，周期性删低 opacity 点，逐步收紧容量。
3. 论文提出剪后 GSDO：坐标嵌入、特征邻域与残差聚合，再用质心对齐和局部平滑损失配合 photometric loss 调整剩余点的空间分布。
4. 公开仓库未找到论文完整图编码器与两项空间损失；README 的位置学习率提高是轻量近似，不能当成完整 GSDO 复现。

### Pipeline

```text
正常增密 + 场景级监测 → 停止增长
→ opacity 正则与渐进剪枝 → 固定点集的图空间恢复（论文方法）
→ 联合光度优化
```

### 关键 score / 公式要记什么

```text
ELBO-inspired 监测量 = 重建误差 + 复杂度代理；
EMA/窗口近乎停滞 → 停止 densification（不是 parent 排名）。
图空间损失约束保留点的整体分布与局部关系（不是 newborn placement）。
```

### 实验要记

Mip-NeRF 360 中，GS² 最终约 0.30M 点，相比 3DGS 约 3.12M；PSNR 27.74 对 27.71，但 SSIM 0.82 对 0.83、LPIPS 0.23 对 0.20。支持大幅减点和 PSNR 接近，不支持全质量指标提升。

### Ablation 结论

Mip 逐步消融中，单加 opacity pruning 后 PSNR 从 ELBO 阶段的 27.73 降至 26.79；后续恢复逐步回到 full model 27.74。恢复阶段是抵消压缩损失的重要部分，不能只复制剪枝比例。

### 局限

完整 GSDO 的公开实现缺口限制直接复现；额外恢复阶段增加训练成本。图邻域也不自动等于同物理表面。

## 24. Plug-and-Play PDE Optimization for 3D Gaussian Splatting (PDEO)

来源：[CVPR 2026 论文](https://openaccess.thecvf.com/content/CVPR2026/html/Mo_Plug-and-Play_PDE_Optimization_for_3D_Gaussian_Splatting_Toward_High-Quality_Rendering_CVPR_2026_paper.html)

### 基本信息

```text
年份/会议：CVPR 2026
所属分类：位置优化 / 邻域协调 / 增密门控
方法阶段：训练迭代更新位置 + densification event
对我重要性：★★★☆
```

### 解决的问题

小 Gaussian 对位置更新敏感，单点梯度可能使点漂移或形成 floater；仅调整加点阈值未必解决优化轨迹不稳定。PDEO 从更新方向的局部协调出发。

### 核心方法

1. 将 Gaussian 的位置更新看作粒子运动，引入具有黏性的局部速度场。这里的“速度”是优化更新量，不是视频物体运动。
2. P2G：把局部粒子的更新聚合到网格，结合历史场的 EMA；G2P：再把网格方向与单点更新混合，修正位置优化。
3. 对过大尺度施加尺度损失，用 confidence/opacity 损失鼓励属性更明确；这些是参数约束，不是 child placement。
4. 在 densification 中用单点与网格更新方向的一致性作辅助门控。方向一致仍不能证明某处缺容量。

### Pipeline

```text
正常渲染反传 → 粒子候选更新 → P2G 局部聚合/历史 EMA
→ G2P 修正位置 → 参数约束与优化
→ 到 event 时检查方向一致性 → 后续增密/剪枝
```

### 关键 score / 公式要记什么

```text
grid_new = lambda_g * grid_old + (1-lambda_g) * mean(local_updates)
particle_new = lambda_p * own_update + (1-lambda_p) * grid_new
```

两个 lambda 分别是网格历史权重与单点更新权重；不能和 FastGS Compact Box 的 beta 或剪枝率混淆。

### 实验要记

精读笔记记录的补充时间：3DGS 33.7 → 38.1 分钟，说明在该组合下训练反而更慢；其他基础方法有缩时案例。质量、显存与 FPS 也需逐指标比较，不能概括成对任意 FastGS 即插即用加速。

### Ablation 结论

笔记核对的 GES 增密消融中，PSNR 贡献约 0.03 dB；整体收益不能都归因于方向门控。移除模块的消融不等于“只加该模块”的独立实验。

### 局限

公开训练实现尚不足以直接核对所有更新接口；网格融合、角度阈值与 optimizer 时序存在复现疑点。FastGS 的短训练中，额外聚合成本尤其需要计入。

## 25. EDGS: Eliminating Densification for Efficient Convergence of 3DGS

来源：[CVPR 2026 论文](https://openaccess.thecvf.com/content/CVPR2026/html/Kotovenko_EDGS_Eliminating_Densification_for_Efficient_Convergence_of_3DGS_CVPR_2026_paper.html)

### 基本信息

```text
年份/会议：CVPR 2026
所属分类：多视角几何初始化 / 容量预分配 / 收敛效率
方法阶段：训练前初始化；主设置训练中不 densify，但仍 prune
对我重要性：★★★★☆
```

### 解决的问题

稀疏 SfM 初始点对表面覆盖不足，训练需花时间通过多轮 clone/split 补齐几何。EDGS 把一部分“哪里该有点”的工作提前到初始化。

### 核心方法

1. 在已知相机的训练图像间做密集对应匹配，结合置信度和双视角三角化产生候选 3D 点。
2. 用重投影误差过滤不可靠候选，并做覆盖/采样控制，避免大量点扎堆在高纹理区。
3. 初始化位置、颜色、尺度及多视角 SH；随后主要作光度优化与剪枝，不再依靠训练中 densification。
4. “无需 densification”不代表没有预处理成本、没有剪枝或从单图直接得到唯一正确几何。

### Pipeline

```text
多视角图像 + 相机 → 密集匹配与置信度
→ 三角化/重投影检查 → 覆盖感知选点
→ Gaussian 位置、尺度、颜色、SH 初始化
→ 常规优化 + pruning（主设置无 clone/split）
```

### 关键 score / 公式要记什么

```text
reprojection error：3D 候选投回两张图，与原对应像素的距离。
SH init：用多视角观测拟合方向颜色系数，而不是训练后 SH 压缩。
```

### 实验要记

Mip-NeRF 360、30K 口径中，论文 3DGS* 为 PSNR 27.49、SSIM 0.816、LPIPS 0.215、26 min、2.8M 点；EDGS 为 28.02、0.839、0.141、27 min、1.9M 点。质量及点数更好，但此设置总时间并未比该 3DGS* 更短。5K/10K 的短训练表现应单独看，不能混用预算。

### Ablation 结论

采样和 SH 初始化分别被消融；SH 初始化的单项对照 PSNR +0.22、LPIPS -0.034，但 SSIM 略降。固定初始点数的采样比较更接近“点放在哪里”的检验。

### 局限

密集匹配和三角化依赖相机、纹理、基线及预处理资源；单目视频若含运动物体，跨时匹配不能直接当同步多视角。与 FastGS 比较须把初始化耗时计入端到端时间。

## 26. VAD-GS: Visibility-Aware Densification for 3D Gaussian Splatting in Dynamic Urban Scenes

来源：[CVPR 2026 论文](https://openaccess.thecvf.com/content/CVPR2026/html/Zhang_VAD-GS_Visibility-Aware_Densification_for_3D_Gaussian_Splatting_in_Dynamic_Urban_CVPR_2026_paper.html)

### 基本信息

```text
年份/会议：CVPR 2026
所属分类：动态城市场景 / 可见性推理 / 几何补点
方法阶段：训练中诊断空缺 → 多视角 MVS → 新点与几何约束
对我重要性：★★★★☆
```

### 解决的问题

稀疏初始化留下真实表面空缺时，背景 Gaussian 可能错误吸收本应由前景承担的图像误差。继续对已有 parent 作梯度 clone/split，未必能把点放到缺失表面。

### 核心方法

1. 将点与观测来源组织成体素，用深度、z-buffer 和可见性线索发现不可靠区域；不是仅统计 radii > 0 的视角数。
2. 对候选区域选择共同可见且具有几何多样性的支持视角，避免把一串几乎重复的相邻帧当强证据。
3. 用 PatchMatch MVS 估计深度/法线并做跨视角过滤；经反投影直接生成新 Gaussian，这条出生路径可绕开“必须有 parent”。
4. 动态刚体在对象局部坐标中做运动补偿，结合实例 mask；之后继续几何/光度优化和原有增密剪枝。

### Pipeline

```text
点云/相机/实例观测 → 体素可见性诊断
→ 选共同可见且有基线的视角 → MVS 深度/法线
→ 一致性过滤 → 反投影新增点 → 几何约束 + 原有训练
```

### 关键 score / 公式要记什么

```text
视角选择同时考虑距离、相对平移和视线方向差；
深度 z 与相机内参 K 给出 X = z K^-1 p。
```

“多视角看到”仍不等于“同一物理表面”；动态数据须先做运动补偿与遮挡检查。

### 实验要记

Waymo 相对 StreetGaussians：整体 PSNR +0.98 dB、动态 PSNR +1.08 dB、SSIM +0.012、LPIPS -0.032。nuScenes 中 SSIM 六场景改善，但相对 StreetGaussians 的 LPIPS 五场景更差、一场景相同；通常点数更多，不是压缩结论。

### Ablation 结论

去掉几何 loss 的设置在部分整体 PSNR/LPIPS 略好，却损失动态 PSNR 与几何表现；几何约束的价值不能只用单个图像指标判断。

### 局限

依赖可靠相机、实例分割、刚体运动和足够视差；非刚体、玻璃、低纹理及遮挡会影响几何证据。公开 dev 代码与正式论文有版本差异。

## 27. RAP: Fast Feedforward Rendering-Free Attribute-Guided Primitive Importance Score Prediction

来源：[CVPR 2026 论文](https://openaccess.thecvf.com/content/CVPR2026/html/Yang_RAP_Fast_Feedforward_Rendering-Free_Attribute-Guided_Primitive_Importance_Score_Prediction_for_CVPR_2026_paper.html)

### 基本信息

```text
年份/会议：CVPR 2026
所属分类：学习式重要性评分 / 剪枝 / 压缩前处理
方法阶段：离线训练评分器；部署时属性特征 → 排序剪枝
对我重要性：★★★☆
```

### 解决的问题

精细的 Gaussian importance 通常需要多视角渲染统计；简单 opacity 排序便宜却忽略属性和邻域。RAP 学可复用的前馈评分器，降低新场景部署时计算重要性的开销。

### 核心方法

1. 从尺度、体积、opacity、DC 颜色、方向颜色变化及 KNN 距离等属性提取原始特征，并计算全局/局部统计，形成每点 15 维输入。
2. 先作分位数裁剪与归一化，再由小 MLP 输出 importance。它预测评分，不从照片预测场景 Gaussian，也不直接决定 child 放置。
3. 训练评分器时用分数软缩放 opacity/scale，通过渲染保真、目标平均分和分数直方图熵约束学习；部署时不做逐视角渲染评分，但仍需 KNN/特征计算。
4. 外部按照目标预算或阈值用分数剪枝。平均分目标不等于严格固定的保留比例，分数也不是“删除后可恢复性”的真值。

### Pipeline

```text
离线：多场景 Gaussian 属性 → 特征 → MLP → 软门控渲染监督
部署：已训练场景 Gaussian → KNN/属性特征 → MLP 分数
→ 按预算排序剪枝 → 可选后续编码/优化
```

### 关键 score / 公式要记什么

```text
每点 7 个全局 + 8 个局部统计 = 15 维；
MLP: 15 → 32 → 32 → 16 → importance。
```

“rendering-free”限定部署时评分，不包括评分器训练。若比 exact Light-T 速度，必须连 KNN、特征提取和加载一起计时。

### 实验要记

论文报告直接剪枝的质量-存储权衡和周期剪枝结果，并非所有场景/指标第一；与 vanilla 比较的四组周期剪枝 LPIPS 均变差。补充材料中评分用时依场景组约 5.72–15.64 s，MLP 前向只占很小部分，主要成本在邻域特征；不能把评分加速写成整个 FastGS 训练或 FPS 加速。

### Ablation 结论

特征与损失消融支持整体评分设计，但不证明任一特征对应某点的因果可恢复性。公开代码只覆盖预训练模型的评分/剪枝组件，完整训练实现未全公开。

### 局限

域迁移、局部 KNN 成本、公开实现与正文特征细节差异均需核查；高压缩及 recovery 场景的排名边界是否稳定，不能由普通剪枝曲线直接推出。

## 28. ResGS: Residual Densification of 3D Gaussian for Efficient Detail Recovery

来源：[ICCV 2025 论文](https://arxiv.org/html/2412.07494) ｜ [官方代码](https://github.com/yanzhelyu/ResGS)

### 基本信息

```text
年份/会议：ICCV 2025
所属分类：Residual Split / 粗细层级增密 / 分辨率日程
方法阶段：训练中 parent-child 动作、监督分辨率和门槛
对我重要性：★★★★☆
```

### 解决的问题

原生 clone 保留覆盖却常复制同样粗的点；原生 split 用更小 child 替换大 parent，可能立即破坏已有覆盖。论文希望大点负责低频覆盖、小点补细节，并使训练从粗到细推进。这里的 residual 指表示分工，不是 child 显式拟合一张 RGB 残差图。

### 核心方法

1. **Residual Split：**在已选中的 parent 椭球内随机采样一个小 child，`s_child=s_parent/1.6`；child 继承原 opacity、旋转和颜色。保留 parent 的位置与尺度，把 parent opacity 乘 `0.3`。原生“删 1 加 2”和这里“留 1 加 1”的名义净增长都为 `+1`，但大 parent 留下可能增加 tile workload。
2. **Image Pyramid：**训练监督分辨率逐层提高。早期先学整体覆盖，后期再要求高频细节；这同时改变像素计算量和屏幕梯度，不只是换图像尺寸。
3. **Varying Gradient Threshold：**为点记录生成层级，训练推进时降低较老层级的增密门槛，使粗层级更易继续产生细点。层级是生成历史，不等于优化后的真实尺度。

### Pipeline

```text
SfM 初始化 → 当前分辨率渲染/反传 → 按层级门槛选 parent
→ 保留并弱化 parent、采样小 child → 更新点集合/优化器
→ 提高监督分辨率、继续优化和清理
```

### 关键 score / 公式要记什么

```text
mu_child ~ N(mu_parent, Sigma_parent),  s_child = s_parent / lambda_s
o_child = o_parent_before,             o_parent_after = beta * o_parent_before
lambda_s = 1.6, beta = 0.3（所查论文/官方函数配置）
```

两点 opacity 不可直接相加推断最终像素不透明度；投影、空间衰减、遮挡和 alpha blending 都会改变结果。

### 实验要记

论文 Mip-NeRF 360 表 3：AbsGS `27.49/0.820/0.191/728 MB`，只加 residual split 后 `27.71/0.827/0.185/712 MB`（PSNR/SSIM/LPIPS/存储）。这是论文体系的模块结果，不是 FastGS 中同容量收益。

### Ablation 结论

动作、金字塔、变化门槛需要分开看；完整方法的结果不能全记给 split。standard 版本并非训练时间/FPS 全面优于 AbsGS。

## 29. Revising Densification in Gaussian Splatting

来源：[ECCV 2024 论文](https://www.ecva.net/papers/eccv_2024/papers_ECCV/html/8041_ECCV_2024_paper.php) ｜ [正文及附录](https://arxiv.org/html/2404.06109)

### 基本信息

```text
年份/会议：ECCV 2024
所属分类：训练期误差归因 / clone opacity 修正 / 增长控制
方法阶段：渲染统计 → ADC event → clone/split → opacity 管理
对我重要性：★★★★☆
```

### 解决的问题

位置梯度不等于当前像素误差，也不等于新增容量的收益；复制 clone 还会突然提高覆盖处的不透明度。若不限制增长，误差驱动的增密可迅速膨胀。

### 核心方法

1. **Error-Based Densification：**由 GT 与当前渲染的像素误差，经 `alpha * transmittance` 混色权重归因给参与该像素的 Gaussian；在 ADC 统计窗口的视角间取 max。高归因不是“错误由此点造成”的因果证明。论文用数值为零的辅助标量在 backward 中读取归因梯度，而不是训练一个重要性 MLP。
2. **Opacity Correction：**只对重合 clone 的 parent/child 同时设 `o_hat=1-sqrt(1-o)`，使中心处二者合成的透射率与旧 parent 相同；远离中心和 split 时不精确守恒。
3. **Growth Control：**全局容量上限和每事件增长限制，候选超额时按分数选。论文所述设置每次最多增长当前规模的 5%；预算约束不保证排序正确。
4. **平滑 opacity 控制：**用温和衰减替代硬 reset，并用残余透射率项约束背景泄漏；不应脱离场景背景设定照搬。

### Pipeline

```text
训练图像渲染/反传 → 累积像素误差的混色权重归因
→ event 按分数和容量选点 → clone/split
→ 对 clone 对称修正 opacity → 平滑衰减、清理、继续训练
```

### 关键 score / 公式要记什么

```text
w_i(p) = alpha_i(p) * T_i(p)
E_i = max_v sum_p [pixel_error_v(p) * w_i^v(p)]
(1-o_hat)^2 = 1-o  =>  o_hat = 1-sqrt(1-o)
```

`o=0.6` 时未经修正的重合 clone 中心合成 opacity 为 `0.84`；对称修正后各约 `0.3675`，中心合成回 `0.6`。

### 实验要记

论文五次训练统计：Mip-NeRF 360 的 3DGS/本文 PSNR `27.45/27.61`，T&T `23.44/23.93`，Deep Blending `29.54/29.50`。训练日程及容量口径不同，不能当作只换 score 的同条件结果。

### Ablation 结论

Mip 表 4 中 baseline 加 opacity correction 的 PSNR `27.65`（baseline `27.45`）；完整方法去掉它为 `27.04`。这说明该模块在论文设置中值得研究，但完整体系的消融差异不能线性加到 FastGS 上。

### 局限

跨视角 max 易受异常视角影响；误差归因不是 split 收益真值；clone 中心校正不是全图守恒。FastGS 已有 VCD/VCP 与不同 reset、候选分布，论文消融不预言这里也有 `+0.2 dB`。

## 30. Pixel-GS: Density Control with Pixel-aware Gradient for 3D Gaussian Splatting

来源：[ECCV 2024 论文](https://arxiv.org/html/2403.15530) ｜ [官方项目](https://pixelgs.github.io/)

### 基本信息

```text
年份/会议：ECCV 2024
所属分类：像素参与量加权 / 跨视角梯度统计 / 深度缩放
方法阶段：训练迭代统计 → ADC event 选点
对我重要性：★★★☆
```

### 解决的问题

普通跨视角平均把一个 Gaussian 在大面积有效像素中参与的观测，与仅覆盖少量像素的观测近似等权处理；但直接强调大面积又会奖励近相机浮点。

### 核心方法

1. **Pixel-Aware Gradient：**统计 Gaussian 在各训练视角真正参与渲染的像素数 `m_iv`，用它加权该视角位置梯度幅值，再除以总参与像素数。它不是 2D 椭圆面积或高残差像素数。
2. **Scaled Gradient Field：**用相机深度与场景半径构造 `f_iv`，压低近相机大投影点的增长倾向；保留远点权重上限 1。深度缩放后的分母仍是 `sum m_iv`，不能同时缩放分母把抑制效果抵消。
3. **后续 ADC：**超过门槛后仍按尺度 clone/split；本文不是 child 放置或 pruning 方法。

### Pipeline

```text
渲染/反传 → 每点每视角梯度、有效像素数、相机深度
→ 深度缩放 + 像素加权聚合 → event 判断 clone/split
→ 原生参数优化与清理
```

### 关键 score / 公式要记什么

```text
g_pixel_i = sum_v(m_iv * g_iv) / sum_v(m_iv)
f_iv = clip((z_iv / (gamma_depth * r))^2, 0, 1)
g_final_i = sum_v(m_iv * f_iv * g_iv) / sum_v(m_iv)
```

`g_iv` 是屏幕位置梯度幅值，不是 RGB 残差；`z_iv` 是相机深度，不是单目预测深度。分母为零时不能执行该统计。

### 实验要记

论文 Mip-NeRF 360：作者重训 3DGS 为 `27.71/0.826/0.202`，Pixel-GS 为 `27.88/0.834/0.176`（PSNR/SSIM/LPIPS）。但效率表中其训练更慢、FPS 更低，不能写成 FastGS 式训练加速。

### Ablation 结论

T&T 表 3 仅像素加权 PSNR `21.80`，完整方法 `24.38`；深度缩放是重要配套。主表和消融表 baseline 存在数值口径差异，不能自行拼接。

### 局限

参与像素多不等于真实表面需要点；近处真实细节也可能被深度缩放抑制。增加逐像素统计可能损害 FastGS 的短训练开销。

## 31. Efficient Confidence-Aware Densification for 3DGS

来源：[arXiv v1 正文与补充材料](https://arxiv.org/html/2610.13541v1)

### 基本信息

```text
年份/会议：2026-10 arXiv 预印本；正式录用未核实
所属分类：固定容量 3DGS-MCMC / 学习式置信度 / 点迁移
方法阶段：训练中源点选择、低贡献点回收与新点初始化
对我重要性：★★★☆
```

### 解决的问题

### 核心方法

1. **Learned Confidence：**逐 Gaussian 学正值 confidence，再按 alpha blending 得到像素 confidence；用像素误差和 `-log(confidence)` 共同约束。低 confidence 表示模型拟合不充分，不是几何错误的校准概率。
2. **分支式源点采样：**约 80% 来源于绝对梯度 rank 与 confidence rank 的组合，随训练逐渐增强 confidence 影响；约 20% 走 SSIM 结构误差归因分支。两分支是分别抽样，不等于两个分数简单线性相加。
3. **Maximum Blending Weight Relocation：**用统计窗口内每点最大的 `alpha*T` 寻找低贡献旧点并迁移，为需求位置腾容量；这是窗口 max，不是累计贡献或 opacity 阈值。新迁移点有短期保护。
4. **出生状态：**新点位置只在出生时采样一次；条件满足时利用训练视角 GT 修正 SH 的 DC 颜色项，并保留高阶 SH。

### Pipeline

```text
固定容量训练并渲染 confidence → 累积梯度/结构误差/最大混色权重
→ 分支抽取源点，同时选低贡献迁移对象
→ 回收名额并在需求处出生 → 初始化位置与 DC 颜色
→ 保护新点、继续优化
```

### 关键 score / 公式要记什么

```text
L_conf(p) = E(p) * C_hat(p) - beta * log(C_hat(p))
固定 E>0 的单像素标量最优：C_hat* = beta / E
w_i = max_(view,pixel) [alpha_i(pixel) * T_i(pixel)]
```

`C_hat*` 只是固定误差的局部数学解释；在混合渲染与参数耦合中不能当逐点真值。源点与迁移对象是两种不同角色。

### 实验要记

论文 Mip-NeRF 360 的 500k 容量消融：3DGS-MCMC `27.30/0.797/0.260`，完整方法 `27.84/0.819/0.231`；分别为 PSNR/SSIM/LPIPS。训练预算与表示机制均非 FastGS。

### Ablation 结论

去掉颜色初始化为 `27.68/0.816/0.236`，去掉位置采样为 `26.96/0.788/0.262`。只替换 sampling 或 relocation 的改善远弱于整套协同；不能把完整收益全部分配给一个 confidence 分数。

### 局限

额外 confidence 渲染、KNN/统计与回收策略都要计时；max 受视角采样影响。低拟合 confidence 不等于 G2 的 depth/normal reliability；固定预算迁移也非 FastGS 原生 VCP。

## 32. SeG-Gaussian: Segmentation-Guided 3D Gaussian Optimization for Novel View Synthesis

来源：[IEEE TVCG 2025 正文](https://iccvm.org/2026/files/papers/ps1_4.pdf) ｜ [作者实现入口](https://github.com/IGLICT/JGaussian)

### 基本信息

```text
年份/会议：IEEE TVCG 31(12), 2025；不是 CVPR 2026
所属分类：分割区域引导增密 / 局部空间正则
方法阶段：训练中区域选点，后半程 KNN/PCA 几何优化
对我重要性：★★★★☆
```

### 解决的问题

仅在少数视角出现的细小区域可能有明显重建误差，却难以靠全局梯度累计越过增密门槛。增点后还可能扎堆或漂浮。分割区域提供**局部比较单元**，不是可靠的三维物体识别结果。

### 核心方法

1. **Segmentation-Guided Densification：**Semantic-SAM 为训练 RGB 生成多层 mask；计算每个 mask 的平均 L1，并与本图全图平均 L1 比较。只在高误差 mask 内，选择该区域像素上最大 `T*alpha` 超过门槛的 Gaussian，交给额外增密。它不是把 mask 内所有点都 split。
2. **局部切平面排斥：**用 Gaussian 中心 KNN 的 PCA 估局部切向基，意图约束点在面内的分布。正文负指数排斥项按字面单独最小化时符号似乎鼓励靠近；未核对代码梯度前不能把“数学上必然排斥”当定论。
3. **法向平滑：**惩罚邻居中心在局部估计法线方向的间距，抑制点偏离当前估计表面；若整片点都落在错误表面，此项仍可能很小。

### Pipeline

```text
训练图像预生成区域 mask → 渲染 RGB 和每点 alpha 贡献
→ 区域平均误差高于全图 → 找区域内高贡献 Gaussian
→ 额外 clone/split → 后半程 KNN/PCA 排斥和平滑 → 继续训练
```

### 关键 score / 公式要记什么

```text
L_mask = 区域内像素 L1 均值；L_image = 全图像素 L1 均值
w_j(mask) = max_(pixel in mask) [T_j(pixel) * alpha_j(pixel)]
触发门：L_mask > L_image 且 w_j(mask) > 0.5（论文设置）
```

第一个门问区域是否相对难拟合，第二个门问该 Gaussian 是否真正参与区域渲染；高误差仍可能来自位姿、反光或遮挡，而非缺点。

### 实验要记

论文比较真实场景和 Blender，并做有限可见视角实验。Semantic-SAM 与固定图块/SLICO/SAM 等 mask 对照中，非语义图块也有作用；训练成本增加，Bicycle 在 RTX 3090 上约 40 分钟，而论文给出的原始 3DGS 约 25 分钟。

### Ablation 结论

mask 类型消融说明区域划分精度有影响，不能说收益全来自“识别物体”。固定容量实验支持局部容量分配，但同上限不等于同最终点数或训练耗时；排斥/平滑的精确独立数值需核原表及实现。

### 局限

mask 是二维区域，不保证跨视角同一物理表面；max 贡献可由个别像素主导；KNN/PCA 对薄物体和错误邻域敏感。正文误差定义与公开 README 片段、排斥项符号均有待代码级核验。

## 33. GeoTexDensifier: Geometry-Texture-Aware Densification for High-Quality Photorealistic 3D Gaussian Splatting

来源：[arXiv v2 正文](https://arxiv.org/html/2412.16809v2)

### 基本信息

```text
年份/会议：arXiv 2412.16809 v2；正式会议状态未核实
所属分类：纹理感知额外 split / 单目深度比校验 / 法线引导 child
方法阶段：训练中候选扩展、parent/child 过滤、位置修正
对我重要性：★★★★☆
```

### 解决的问题

仅用“一个 Gaussian 在多少像素上贡献最大”找模糊大点，会把无纹理墙面与细纹理区域混为一谈；随机 split child 又可能离开表面，弱纹理处后续难以纠正。

### 核心方法

1. **Texture-Aware Densification：**为训练图像像素计算纹理梯度权重；只对 Gaussian 是最大贡献者的像素累积权重，得到纹理加权的最大贡献面积，随训练降低额外 split 阈值。它补充原生 ADC，不是直接替换 FastGS VCD。
2. **VDRC：**为 Gaussian 选贡献最大的参考训练视角，比对单目预测深度与 Gaussian 相机深度的比值；先检 parent 的比值漂移，再检 child 相对 parent 的变化。比值试图抵消部分尺度差，但不能提供真值深度。
3. **Normal-Guided Placement：**先随机生成 child 候选，再用估计法线投到 parent 附近的切平面，并按图像纹理调整投影与原始位置的混合。它改 child 出生位置，不是 G2 的 parent score。

### Pipeline

```text
原生训练/ADC + 纹理加权贡献面积找额外 split parent
→ 参考视角与 parent 深度比检查 → 随机 child 候选
→ 法线/纹理引导位置 → child 深度比检查或回退 parent
→ 继续常规优化
```

### 关键 score / 公式要记什么

```text
S_hat_i = sum_(winner pixels p) texture_weight(p)
R_v(G) = D_mono(proj_v(mu_G)) / Z_v(G)
P_v(parent,child) = |R_v(parent)-R_v(child)| / R_v(parent)
```

论文纹理权重式按字面在零梯度处也接近 1，深度比阈值的正文两处叙述方向相反，位置混合式的二维图像梯度与三维向量乘法定义不完整；**未核官方实现前不要自行修正公式并称为作者实现**。

### 实验要记

主表中 Truck 原始 3DGS/本文 PSNR `23.157/23.199`，Train `21.269/21.264`，并非两场景都提升。Bonsai 的论文设置下训练比 Mini-Splatting-D 更慢、显存更低、FPS 更高；不等于 FastGS 短训练收益。

### Ablation 结论

Mip 九场景表中 Only Tex PSNR 简单平均约 `27.596`，Tex+VDRC 约 `27.594`，Tex+Normal 约 `27.632`，Full 约 `27.694`。VDRC 单独接在 Tex 后的平均 PSNR 没显著正向信号；组合结果不能反推每一模块独立有效。

### 局限

单目深度与法线在遮挡、反光、远背景和薄结构处不可靠；过滤 child 会改变最终点数。论文 Horse/Truck 的远背景失败例提示：过强深度比门可能误杀必需的 child。

## 34. IndoorGS: Geometric Cues Guided Gaussian Splatting for Indoor Scene Reconstruction

来源：[CVPR 2025 正文](https://openaccess.thecvf.com/content/CVPR2025/papers/Ruan_IndoorGS_Geometric_Cues_Guided_Gaussian_Splatting_for_Indoor_Scene_Reconstruction_CVPR_2025_paper.pdf) ｜ [补充材料](https://openaccess.thecvf.com/content/CVPR2025/supplemental/Ruan_IndoorGS_Geometric_Cues_CVPR_2025_supplemental.pdf)

### 基本信息

```text
年份/会议：CVPR 2025
所属分类：室内几何初始化 / 来源分流 ADC / 几何监督
方法阶段：训练前线索生成 → 训练中优化、增密与剪枝
对我重要性：★★★★☆
```

### 解决的问题

室内白墙等弱纹理区域缺 SfM 种子，错误点又可能在 ADC 中被放大。纯 RGB 监督能解释照片的几何解不唯一；只改变 child 方向不足以概括这篇完整方法。

### 核心方法

1. **三类线索初始化：**RGB 与预测法线图提取 2D 线并跨视角匹配成 3D 线点 `G_L`；对 SfM 点做空间离群过滤得 `G_M`；用 SAM 弱纹理区域、Metric3D 深度和稀疏线/SfM 深度对齐补平面状点 `G_S`。类型按来源而非物体语义，child 继承类型。
2. **来源分流 ADC：**线点重点在切平面增密；SfM 点按训练阶段暂停/恢复常规 ADC；平面状点可能有深度偏移和重复，因此不 clone/split，但仍优化、剪枝。
3. **线点法线与 child 位置：**只对线来源点加最短尺度变扁损失，并用单目法线约束渲染法线；旋转后的最短轴才作为局部法线近似。split 将随机局部偏移的最短轴分量置零；clone 的意图是从三维位移中去掉法向分量。正文式 (11) 存在向量/标量书写歧义，规范投影只是解释式，未核官方代码。
4. **几何损失：**训练时结合 RGB、局部深度相关性、单目法线、变扁和渲染深度/法线一致性。§3.2 的逐 Gaussian 局部平面深度/法线 alpha 合成，不等于简单把最短轴着色，也不等于 alpha 加权中心深度反推法线。

### Pipeline

```text
多视角 RGB/相机 → 线/SfM/平面状 3D 线索 → 分型初始化
→ 渲染 RGB、深度、法线并优化损失
→ 按来源决定 ADC；线点切平面 clone/split
→ 继续几何约束、参数优化及剪枝 → 新视角和几何评估
```

### 关键 score / 公式要记什么

```text
n_flat = R * onehot(argmin(s_1,s_2,s_3))
v_tangent = v - (v dot n_flat) * n_flat（几何解释式）
split：在 parent 局部坐标采随机偏移，再将最短轴分量设为 0
```

切平面限制 child **出生位移**，不证明 parent 已在真表面，也不保证 child 后续优化不会漂。最短轴方向若错，投影可能删除正确的切向位移。

### 实验要记

论文在 Replica、ScanNet++、Deep Blending 等室内数据上评价新视角渲染及几何；总体提升混合了初始化、ADC 与多个几何损失，不能归因于切向 split 单模块。完整设置和数字详见独立精读笔记的实验/消融段。

### Ablation 结论

应区分移除线索、改变 ADC 与去掉几何损失的对照。正文表格勾选有提取疑点，尚不能从整体表值推导任一模块对 FastGS 的 PSNR 增幅。论文自身也未验证“任意未扁平化 FastGS Gaussian 的最短轴都是真法线”。

### 局限

线匹配、单目深度/法线和弱纹理区域判断都可能错误；三类来源带来额外预处理成本，且论文面向室内结构。线处两片表面可能有不同法线，单一切平面并不总清楚。
